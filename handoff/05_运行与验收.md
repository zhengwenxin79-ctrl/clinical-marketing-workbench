# 运行与验收

所有命令从项目根执行。Windows把python3换成py -3 -X utf8。

## 离线检查

```sh
python3 tools/verify_package.py --check-manifest
```

只读研究库和原始资料，结果写handoff/acceptance/P00/offline.json。--check-manifest用于初次解压完整性核验；开发有意修改后应记录差异，不覆盖原打包基线伪装未改。

## 打开页面

直接打开打开工作台.html，或workbench/领域工作台/index.html#market、#sales。文件地址与localhost端口是不同存储环境，实际业务记录先导出。

如需本机HTTP预览：`python3 tools/serve_preview.py --port 8767`，访问终端网址；Ctrl+C停止。仅绑定127.0.0.1，不启动维护台或采集。

## 隔离重建

```sh
python3 tools/build_workbench.py
```

将workbench复制到handoff/acceptance/build-preview/workbench，执行当前只读生成器与领域核验，不改主副本或数据库。修改src后要重建HTML；原生成器也可在workbench内手动执行，但不是P00的默认动作。

## 浏览器验收

已配置Playwright时：`node tools/browser_smoke.cjs`。依赖缺失先报告；后续获准配置环境时可npm install，再npx playwright install chromium。可设PLAYWRIGHT_MODULE为已安装模块路径；设AUTOMATION_BROWSER_EXECUTABLE_PATH为专用浏览器路径。

脚本用临时独立profile，关闭后清理；不启动日常Chrome。覆盖市场分配、销售PI资料/收藏/两类反馈、未保存保护、旧链接、六入口、手机。结果写handoff/acceptance/P00/browser。

## 原维护台

后续确需维护时才执行 `python3 workbench/脚本/启动维护台.py --port 8789`。它有写库操作，不在P00中点击确认导入，不当作销售共享后端。

本包未在新的Windows/Antigravity实机运行；本机独立解压和浏览器验收结果另见package verification。
