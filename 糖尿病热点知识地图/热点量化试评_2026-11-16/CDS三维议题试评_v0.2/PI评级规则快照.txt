# 临床科研客户深度调研 Skill V3

**版本**：V3.2（PubMed核实强化版）
**定位**：融合 client-deep-dive（产品契合度）+ customerResearch（PubMed文献）的全部优势
**输出**：HTML单页报告（六栏标准结构）+ 可选「详细论文报告」（深度论文解读）
**模板**：元 `references/card_template.html` 中的标准模板，替换 `{{占位符}}` 生成最终报告
**⚠️ 核心原则：信息准确性是第一要求，PubMed是论文核实的金标准**

---

## 触发条件

用户提到以下任一场景时触发：

- 批量调研PI客户信息（风湿免疫科/肿瘤科/自免疾病）
- 调研[姓名] [单位] 背景
- 需要深度了解某PI的学术脉络
- 要求生成HTML调研报告
- 需要产品线契合度评估

## 二、研究方向 + 研究脉络

### 方向描述

- **主攻方向**：一句话提炼核心领域
- **覆盖疾病**：用标签（tags）列出所有涉及的疾病/技术方向
- **描述段落**：2-3句话说明研究聚焦

### 研究脉络时间线

按年份倒序，5-7个关键里程碑节点，格式：

```
年份 → 事件描述
2011—2013 → 建立队列
2016—2020 → 国自然主持
2022 → 重要论文发表
2024 → 牵头共识制定
2025 → 高IF论文发表
2026 → 最新成果
```

## 三、近三年发表论文（2024—2026）⚠️ PubMed核实是硬性要求

每篇论文包含：

- 论文标题（英文原文 + 中文摘要）
- **IF影响因子**（黄色醒目标签，必须查询最新年度数据）
- 期刊名称
- 发表年份（**必须以PubMed为准，不可用新闻稿日期代替**）
- 作者排名（第一/共同第一/通讯/重要贡献者）
- **PubMed/DOI/PMC标识**（每篇论文必须附带可溯源的标识符）
- 备注（如"中国最大样本队列"）

论文数量：3-7篇核心论文（按年份倒序排列）。

### ⚠️ 论文核实强制流程（不可跳过）

```
1. WebSearch初筛 → 找到候选论文
2. PubMed逐篇核实 → 确认：
   a) 论文标题完全一致
   b) 期刊名称正确
   c) 发表年份以PubMed为准（Epub日期≠正式发表日期）
   d) 作者列表中包含目标PI
   e) IF查询最新年度数据（不可凭印象）
3. 记录PubMed/DOI/PMC标识 → 写入报告
4. 无法在PubMed找到的论文 → 直接删除，不保留
```

### 论文内容深度解读格式（可选详细论文报告）

当用户要求「详细论文报告」时，每篇论文需增加以下深度解读：

```
痛点 → 该研究要解决的临床/科学问题
技术突破 → 使用的关键技术方法
核心发现 → 最重要的研究结果
成果意义 → 对领域的贡献和转化潜力
```

│ 二、研究方向 + 研究脉络（时间线）              │
│ 三、代表性论文（按年份倒序，含深度解读）        │
│    - 核实说明（全部经PubMed独立验证）          │
│    - 每篇论文：标题+期刊+IF+时间+DOI          │

## 数据核实体系（防幻觉） ⚠️ 核心机制

### 三层核实等级

| 等级 | 核实标准 | 标注格式 | 适用范围 |
|------|----------|----------|----------|
| **A级**（强证实） | 2+独立来源交叉验证 | 不加标注（默认可信） | 职称/科室/论文/基金 |
| **B级**（弱证实） | 1来源 + 有关联佐证 | 字段后标注「（B级核实）」 | 海外经历/学术活动 |
| **C级**（推断） | 0直接来源，基于逻辑推断 | 字段后标注「C级推断」 | 年龄/未公开信息 |

### 强制标注规则

```
A级 → 正常展示，无需额外标注
B级 → 字段值后灰色小字「（B级核实）」
C级 → 字段值后灰色小字「C级推断」
```

### 防幻觉红线（绝对禁止）

| ❌ 禁止行为 | ✅ 正确做法 |
|------------|------------|
| 虚构年龄 | 标注「未知」或C级推断 |
| 编造学历/毕业院校 | 仅输出经核实的 |
| 夸大任职（如"常委"→实际为"委员"） | 使用原文职衔，不升级 |
| 伪造论文标题/DOI | 仅输出PubMed/官网验证的论文 |
| 杜撰基金编号 | 仅输出NSFC官网可查的 |
| 将国际会议算作国内活动 | 仅调研国内学术活动 |
| **用新闻稿日期代替论文发表时间** | **发表时间必须以PubMed为准** |
| **凭印象填写IF** | **IF必须查询最新年度数据** |
| **保留PubMed找不到的论文** | **无法验证的论文直接删除** |
| **仅凭WebSearch确认论文存在** | **必须到PubMed逐篇核实** |

### 核实流程图

```
信息采集 → 多源交叉验证 → 分级标注 → 不确定字段留C级 → 从未被证实的字段不输出
```

## 综合评分逻辑

### 评分维度与权重

| 维度 | 权重 | 满分 | 评分要点 |
|------|------|------|----------|
| **研究方向契合度** | 30% | 30 | PI主攻疾病 × 吉因加产品线覆盖度 |
| **学术产出质量** | 25% | 25 | 近3年论文IF总分 / 论文数量 + 期刊档次 |
| **科研转化潜力** | 25% | 25 | 主持基金级别（国自然/重点研发）+ 队列规模 + 临床试验经验 |
| **平台资源禀赋** | 20% | 20 | 医院等级 + 科室全国排名 + 学术任职层级 |

### 各维度详细打分标准

#### 1. 研究方向契合度（30分）

| 分值区间 | 条件 |
|----------|------|
| 25-30 | 主攻疾病与吉因加产品线高度重合（风湿免疫+单细胞/多组学） |
| 18-24 | 相关领域，可横向拓展 |
| 10-17 | 部分相关，需定制方案 |
| 0-9 | 不相关 |

#### 2. 学术产出质量（25分）

| 分值区间 | 条件 |
|----------|------|
| 20-25 | 近3年有IF>15论文，或累计IF>40 |
| 14-19 | 近3年有IF>8论文，或累计IF>20 |
| 8-13 | 近3年有SCI论文，IF 3-8 |
| 0-7 | 近3年无SCI论文 |

#### 3. 科研转化潜力（25分）

| 分值区间 | 条件 |
|----------|------|
| 20-25 | 国自然主持2+项 或 重点研发项目骨干+多中心RCT牵头 |
| 14-19 | 国自然主持1项 + 有队列 |
| 8-13 | 省自然/院级基金 + 有小规模队列 |
| 0-7 | 无独立基金 |

#### 4. 平台资源禀赋（20分）

| 分值区间 | 条件 |
|----------|------|
| 16-20 | 协和/北医/复旦附属类顶级三甲 + 科室全国TOP5 |
| 11-15 | 三甲医院 + 科室区域知名 |
| 6-10 | 三甲医院 |
| 0-5 | 非三甲 |

### 总分等级映射

| 分数区间 | 等级 | 颜色 | 说明 |
|----------|------|------|------|
| 90-100 | **A级** · 高优先 | 🟢 青色 | 立即跟进，核心KOL |
| 75-89 | **B级** · 中等 | 🔵 蓝色 | 重点培育 |
| 60-74 | **C级** · 观察 | 🟡 黄色 | 定期监测 |
| <60 | **D级** · 暂缓 | ⚪ 灰色 | 低优先级 |

### 评分计算示例（彭琳一）

```
维度1：研究方向契合度 → IgG4-RD+风湿免疫高度契合单细胞多组学 → 27/30
维度2：学术产出质量   → 近3年ARD(IF=20.6)+A&R(IF=10.9) → 23/25
维度3：科研转化潜力   → 国自然2项+重点研发骨干+WInS多中心RCT牵头 → 24/25
维度4：平台资源禀赋   → 北京协和医院(全国TOP1)风湿免疫科 → 19/20

总分 = 27 + 23 + 24 + 19 = 93分 → A级 · 高优先
```

## 6步法工作流（V3.2标准）

### Step 1: 数据库检索（必先执行）

从客户数据库（1163条）检索：
- 精确匹配：PI姓名 + 单位
- 命中 → 直接获取完整字段，跳至Step 4
- 未命中 → 进入Step 2

### Step 2: 多源并行调研

**必须执行的6个数据源**（并行调用）：

| 数据源 | 查询内容 | 优先级 |
|--------|----------|--------|
| PubMed | PI姓名 + 关联疾病关键词 | P0 |
| WebSearch | PI姓名 + 单位 + 科室 + 任职 | P0 |
| 医院官网 | 医生简介/出诊信息/专家介绍 | P0 |
| NSFC基金 | 负责人姓名 + 单位 | P1 |
| 微信公众号(wechat-article-search) | PI姓名 + 方向关键词 | P1 |
| WebSearch扩展 | PI姓名 + 学术会议 + 年份 | P1 |

### Step 3: 论文PubMed核实（⚠️ 强制步骤，不可跳过）

对Step 2中发现的每篇论文，**必须执行以下核实流程**：

```
1. 记录候选论文：标题+期刊+年份+作者
2. PubMed逐篇搜索：用论文标题精确搜索
3. 核实5要素：
   a) 标题完全一致 ✓
   b) 期刊名称正确 ✓
   c) 发表年份以PubMed为准（Epub≠正式发表）✓
   d) 作者列表包含目标PI ✓
   e) IF查询最新年度数据 ✓
4. 记录标识符：PubMed ID / DOI / PMC ID
5. 无法验证 → 直接删除，不保留在报告中
```

**⚠️ 关键教训（来自周一鸣调研）**：
- 医院新闻稿日期 ≠ 论文发表日期（新闻稿可能滞后数月）
- Epub日期 ≠ 正式发表日期（以PubMed Volume/Issue为准）
- IF必须查最新年度，不可凭印象
- 同一PI可能有多篇相似标题论文，需逐一核实

### Step 4: 数据核实与分级

按三层核实体系对每条信息进行：
1. 交叉验证：至少2源确认A级字段（职称/科室/论文等）
2. B级标记：仅1源确认的海外经历、学术活动等
3. C级标记：推断信息（年龄为主）
4. 未证实信息：直接不输出

### Step 5: 综合评分

按四维度打分标准逐项评分，得出总分和等级。

### Step 6: HTML报告生成

**选项A：标准六栏报告**（默认）
1. 读取 `references/card_template.html` 模板文件
2. 将所有 `{{占位符}}` 替换为调研结果数据
3. 保持CSS样式完完全全不变（深色科技风，色号 #1a1a2e, #00f5d4, #fbbf24, #22c55e 等）
4. 生成 `{PI姓名}_card.html`

**选项B：详细论文报告**（用户要求时）
1. 参考周一鸣详细论文报告格式
2. 每篇论文增加深度解读（痛点/技术突破/核心发现/成果意义）
3. 顶部增加核实说明
4. 底部增加产品线契合度评估
5. 生成 `{PI姓名}_详细论文_card.html`

**关键规则**：
- 学术任职卡片必须 `grid-column: span 2;`
- B级核实字段后标注 `（B级核实）`
- C级推断字段后标注 `C级推断`
- 未证实字段不输出，标注「—」或「待核实」
- **论文发表时间必须以PubMed为准**
- **每篇论文必须附PubMed/DOI/PMC标识符**

### Step 7: 输出交付

输出 `{PI姓名}_card.html`（或详细版），通过 deliver_attachments 交付给用户。

## 注意事项

1. **年龄推断规则**：无直接来源时标注「C级推断」，不虚构
2. **学术委员必须全部列出**：每个具体委员会身份逐条展示
3. **数据库优先**：1163条客户数据优先匹配，命中则直接使用
4. **未证实不输出**：任何未经核实的字段不出现在报告中
5. **核实等级透明**：B级/C级必须在字段旁标注
6. **⚠️ 论文发表时间必须到PubMed核实**：不可用新闻稿日期、在线发表日期或其他来源代替
7. **⚠️ IF必须查询最新年度数据**：不可凭印象填写，每次调研都需查询
8. **⚠️ 不确定的论文直接删除**：宁可少列也不可列错
9. **⚠️ 用户明确要求"保证信息准确无误"**：这是硬性要求，不可妥协

## 技能包结构

```
clinical-research-v3/
├── SKILL.md                        ← 主指令文件（本文件）
└── references/
    └── card_template.html          ← 标准HTML模板（所有占位符见下方说明）
```

### 模板占位符说明

| 占位符 | 对应内容 | 数据类型 |
|--------|----------|----------|
| `{{PI_NAME}}` | PI姓名 | 单值 |
| `{{HOSPITAL}}` | 单位全称 | 单值 |
| `{{DEPARTMENT}}` | 科室 | 单值 |
| `{{DATE}}` | 调研日期 | 单值 |
| `{{SCORE}}` | 综合评分数值 | 单值 |
| `{{GRADE}}` | 评分等级（A/B/C/D） | 单值 |
| `{{PRIORITY}}` | 优先级（高优先/中等/观察/暂缓） | 单值 |
| `{{DEPT_CATEGORY}}` | 科室大类（内科/外科/医技） | 单值 |
| `{{DEPT_FULL}}` | 完整科室名 | 单值 |
| `{{TITLE}}` | 职称 | 单值 |
| `{{DEGREE}}` | 学历 | 单值 |
| `{{SCHOOL}}` | 毕业院校 | 单值 |
| `{{ACADEMIC_TITLE}}` | 学术职称（博导/硕导/—） | 单值 |
| `{{ACADEMIC_TITLE_NOTE}}` | 学术职称备注 | 单值 |
| `{{OVERSEAS}}` | 海外经历描述 | 单值 |
| `{{OVERSEAS_VERIFY}}` | 海外经历核实等级标注 | 单值 |
| `{{ACADEMIC_ROLES}}` | 学术委员身份列表（逐条HTML） | HTML片段 |
| `{{AGE}}` | 年龄推断值 | 单值 |
| `{{MAIN_DIRECTION}}` | 主攻方向 | 单值 |
| `{{DIRECTION_DESC}}` | 研究方向描述 | 单值 |
| `{{TAGS}}` | 疾病/技术标签（多个span.tag） | HTML片段 |
| `{{TIMELINE_ITEMS}}` | 研究脉络时间线 | HTML片段 |
| `{{YEAR_RANGE}}` | 年份范围 | 单值 |
| `{{PAPER_ITEMS}}` | 论文列表 | HTML片段 |
| `{{TALK_ITEMS}}` | 演讲活动列表 | HTML片段 |
| `{{FUND_ITEMS}}` | 基金课题列表 | HTML片段 |
| `{{WECHAT_ITEMS}}` | 微信文章列表 | HTML片段 |

### 片段型占位符示例

**{{TAGS}} 示例**：
```html
<span class="tag">IgG4-RD</span>
<span class="tag">类风湿关节炎</span>
<span class="tag">强直性脊柱炎</span>
```

**{{PAPER_ITEMS}} 示例**：
```html
<div class="paper-item">
    <div class="title">
        论文标题（英文）
        <span class="if-badge">IF=20.6</span>
    </div>
    <div class="meta">期刊名 · 年份 · 作者排名 · 备注</div>
</div>
```

**{{TIMELINE_ITEMS}} 示例**：
```html
<div class="tl-item">
    <div class="year">2011—2013</div>
    <div class="event">事件描述</div>
</div>
```

## 安装方式

将整个 `clinical-research-v3/` 文件夹复制到目标设备的工作 buddy skills 目录：

```bash
# 用户级（推荐，所有项目可用）
~/.workbuddy/skills/clinical-research-v3/

# 项目级（仅当前项目可用）
{项目目录}/.workbuddy/skills/clinical-research-v3/
```

安装后无需任何配置，直接通过自然语言调用：

```
用 clinical-research-v3 调研 [姓名] [单位]
```
