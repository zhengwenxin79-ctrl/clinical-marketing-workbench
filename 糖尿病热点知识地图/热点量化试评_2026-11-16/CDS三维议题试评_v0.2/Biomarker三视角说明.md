# 本轮复核了什么

- CDS 2026既有606条学术报告，逐条审阅题名并形成台账。
- 80条题名归入本轮标志物相关范围：可测生物特征连接临床用途/关联，或明确的标志物发现方向，覆盖分子、影像、生理和复合特征。仅表示讨论方向，尚不代表已有结果或性能。
- 另14条有预测/分型方向，但输入或指标未明，单列；27条培训/方法/综合背景、2条常规指标/参数背景、5条机制参考及478条其他背景均保留原题与归类理由。
- 当前80条中7条明确绑定现有词条，剩余73条以原题、特征描述、主讲人和来源展示，等待细分“指标×用途×输入”。没有把近似题名扩充到现有词条。
- ADA继续使用既有27条定向关联记录，论文主线仍为既有17篇；不新增联网资料。
- 当前仍为28个词条，含2个常规参照。转化分类为6项优先复核、11项继续验证、9项方向观察、2项参照用途。

以上为AI题名复核，边界与归类待mentor校准。已有原文读取层次继续逐条保留，没有把题名补写成研究结论。

# 数量如何计算

CDS词条报告数按原始报告ID去重。占比＝本词条明确绑定的标志物相关报告数÷80。词条为指标类别时，类别内成员、组合与用途继续分开列出；这不是某个单分子的热点比例。一个报告可含多个指标，占比之和不要求为100%。

ADA没有完整覆盖分母，显示现有绑定记录数和原始来源；其中部分是关联论文更新，日期与层次逐条显示，不全部视为现场已报告结果。

有结果研究线索按研究身份保守去重：A01/R03为同研究；A24/A25共享队列；A21/R13可能重叠；A05/A18疑似同源，A18报道不新增研究组。独立研究和独立团队数未完成核查时显示“待核”，不填0。

时间窗固定为2026-08-19至2026-11-16。按已读结果的可核首发日期计去重研究组；未知日期保留待核，计划报告日、卷期日和采集日不代替首发日。无可比历史时不标热度上升。

# 本轮修正了哪些证据角色

1. **胰岛自身抗体**：补入已有CDS OR_087与OR_329，与原S_029共同保留；分别是抗体谱协同、亲属筛查和异质性/检测讨论。R04中抗体阳性是入组背景，不再算作抗体新检测性能研究。具体IA-2A、ZnT8等原题成员与组合性能要单独核实。
2. **C肽**：R04的进展风险用途、A19的免疫治疗终点方法、R05的应答结局分别列明；不混成同一用途的独立复现。
3. **游离脂肪酸、甘油三酯、MAGE、短链脂肪酸**：显式保留未见增益、未支持替代或阴性关联，不将研究出现视为支持临床应用。
4. **诱导转录特征**：保留验证队列部分临床关联未复现的缺口；测量对象是报告细胞转录反应。
5. **尿液MALAT1**：保留尿液细胞输入的验证用途，其他组分与PVT1各自复核；原研究的验证记录不等于外部团队复现。

没有做近似绑定：产短链脂肪酸菌群不等同SCFA水平；胰岛素/C肽比值不等同C肽单项的新用途；纵向队列蛋白组不证明重复测量蛋白；一小时血糖标准不等同餐后一小时增幅；TyG复合指数不等同甘油三酯单项。

# 关注与转化怎样判断

“候选线索”表示已有明确来源；“会议集中讨论”要核相同指标及用途在完整材料内的多条讨论；“多团队跟进”要核不同研究与团队的独立性；“持续关注”要有可比连续窗口。不同类别可并存，但现有数量不足以自动赋予这些标签。

转化优先独立判断：人体用途明确、原研究已有值得复核的验证结果或重要临床问题，可列“优先复核”；只有候选发现或内部模型，列“继续验证”；主要为机制、题名、方法待结果，或目标关联缺乏支持，列“方向观察”。每项同时列人体证据、验证、临床增益、技术参与和待补内容。没有把优先级解释为临床准入或公司已有试剂盒。
