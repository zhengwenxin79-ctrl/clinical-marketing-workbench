# 本轮要看什么

从“某一场会议讲什么”，扩展到“这个领域的同类问题被哪些会议和团队讨论，具体指标已经验证到哪里”。热点与临床转化分开判断，客户机会不进入本次排序。

打开同目录 `index.html`，使用顶部三个入口：

| 入口 | 回答的问题 | 本轮交付 |
|---|---|---|
| 会议议题 · CDS | 本届谁在讲什么，排序依据是什么？ | 保留原44个议题、12个板块、606条学术报告，原分值与报告占比不变。 |
| 领域议题 | 不同会议和论文中的同类问题如何汇合？ | 45个稳定议题ID，逐条绑定CDS、ADA与论文，展示团队、资料量、去重研究线索组和评分缺口。 |
| Biomarker热点 | 哪些具体指标值得追踪、验证或优先复核？ | 28个已有词条，按早期识别、分型与预测、动态监测、其他筛选；支持技术关联和转化优先筛选。 |

专家动向和评分与来源继续单独可访问。原始资料入口、数据下载和旧路由保留。本轮不修改正式站、项目主页、框架汇总或GitHub。

# 已接入的资料

- CDS 2026完整日程中的606条学术格式报告；579条进入原CDS榜，其余27条保留单列。
- ADA 2026已有27条定向关联记录，其中部分已接14篇原始论文摘要；并非全会普查。
- 原论文主线17篇记录。它们与ADA关联记录不能简单相加为独立研究数。
- 已有28个Biomarker/组合/参照指标，复用原台账的来源、输入及技术关联。

统一证据ID为 `C-原报告编号`、`A-原ADA记录ID`、`P-原论文记录ID`。原ID保留，便于回溯。研究描述来自已有中文台账；本轮没有新增联网查证，因此原资料中的结果、团队与公司服务状态仍需按原读取层次理解。

# 领域量化怎么解释

预留四维：会议覆盖30、有结果研究线索组30、有依据学术带头角色20、近90天研究更新20。日期窗口固定为2026-08-19至2026-11-16；未来报告日、卷期日和入库日不代替首发日期。

当前ADA覆盖分母不完整，因此**不生成领域总热度**。已有研究组、角色及近期更新，在资料足够时按 `权重×ln(1+已知量)/ln(1+全目录最大已知量)` 提供分项试算。缺项保留“待补”，不填0；小计不换算100分、不用于不同可计分项之间的混排。

页面的“资料支持榜”按已见会议数→有结果研究线索组数→有依据角色数排列，同值按ID。这回答的是当前资料支持程度，尚不足以推断领域总体热度。CDS完整日程与ADA定向样本的数量分开显示，保留国内/国际和计划/结果层次。

统一目录新增F45“循环蛋白特征与糖尿病发病风险”，承接R03/A01及CDS OR_318的相关临床问题；OR_318在原CDS榜的归属保持不变。相同议题关联不表示同一研究、同一指标组合或已相互验证。

# 去重与独立性

| 情况 | 本轮处理 |
|---|---|
| A01 / R03 | 同一研究会议与论文版本，合并一组。 |
| A05 / A18 | 疑似同源，保守合并；A18为报道级补充，不新增有结果研究组。 |
| A21 / R13 | 可能存在样本重叠，保守合并用于研究线索组；尚未断言同一研究。 |
| A24 / A25 | 同队列不同分析，合并一组；分别保留不同指标用途。 |
| CDS题名 | 保留计划讨论方向，不凭题名推断独立研究身份或结果。 |

“去重研究线索组”不等于经核独立研究或独立验证。尤其不同TrialNet研究仍需核注册号、队列及样本重叠。

# Biomarker怎么显示（当前版）

使用会议关注、研究跟进、转化优先三个视角。报告数、会议内占比、团队、结果与验证分别展示；词云统一20px用于导航。取消Biomarker综合关注分、加权名次及按分数生成的字号。

CDS606条学术题名已按本轮规则复核，80条标志物相关题名中7条绑定当前词条，其余73条按原题单列。ADA27条为定向样本，不计算全会占比。28个词条按具体分子、组合、类别、生理指标、机制来源及四类临床用途筛选。

同一指标不同用途、样本和入组/终点角色分开呈现。R04中抗体用于定义入组人群，相关研究背景保留；未计入抗体新检测研究。阴性、未见增益及验证不一致的结果继续保留。转化优先分优先复核、继续验证、方向观察，常规参照另列。

详细口径、复核数量和已有资料修正见 [[Biomarker三视角说明]]。学术关注、临床验证与公司交付适配分别判断。

# 一个贯穿案例

从“领域议题→GDM早期识别与孕期管理（H30）→35基因RNA组合”进入：

1. 会议层：查看CDS有关GDM的计划讨论与ADA已有GDM研究；它们提供问题背景，不被写成已讨论该35基因组合。
2. 论文层：R16研究孕约16周血浆cf-mRNA/cf-lncRNA，已有内部AUC 0.84、外部验证0.73记录。在线日是2026-02-09，不把12月卷期当新发表。
3. 指标层：保留“35基因组合”，原台账未列成员，不拆出假定基因。当前一组研究，属于候选；V3只描述原研究已有外部验证记录。
4. 公司环节：可讨论血浆RNA候选筛选、独立验证与模型增益评价；先补外部验证人数、基因成员、跨中心设计、校准及相对临床基础模型增量，再核公司流程。

# 以后其他会议如何补充

先沿用统一目录，不为每场会议另起一套无法比较的主题。

1. 登记会议名称、年份、国内/国际、官方入口、日程/摘要覆盖范围和取得日期。
2. 每条记录至少保留：原始ID、原题、主讲人/团队、单位、日期依据、阅读层次、原始链接、样本与方法、结果或结果缺口。
3. 映射到已有稳定议题ID；新问题先建候选，并记录边界与归类理由。一个报告保留一个主要议题，跨题标签不重复加分。
4. 用DOI、注册号、队列及样本核对会议/论文版本，分别保存“确定同源”“可能重叠”“独立性未核”。
5. 确认具体指标后绑定Biomarker，分别记录样本、用途、方法、验证和公司研究环节。
6. 人工复核后扩展本地数据构建器的来源与映射，重算并留版本快照。接入新会议还需增加其展示分组与覆盖分母；本轮没有启动自动接入或抓取。

字段样板见 `领域与Biomarker_工作资料/下一场会议接入样板.json`。它是待复核数据约定，当前不自动导入，以避免未核资料改变榜单。

# 文件与维护

- `构建领域与Biomarker数据.py`：从本地旧台账读取，做领域映射、去重和验证阶段记录。
- `生成会前重点议题榜.py`：保留原CDS构建逻辑，接入新增数据并生成单文件页面。
- `会前重点议题模板.html`：当前页面模板；构建时自动嵌入 `领域与Biomarker_工作资料/扩展界面.js`，生成页面仍是可离线访问的单个HTML。
- `领域与Biomarker_工作资料/统一领域与Biomarker数据.json`：本轮结构化证据、领域与指标输出。
- `领域与Biomarker_工作资料/议题映射与去重规则.json`：可审查的映射和同源规则快照。
- `领域与Biomarker_工作资料/扩展前快照/`：扩展前页面、数据与生成器备份。

在本目录执行 `python3 生成会前重点议题榜.py` 可离线重建。不会访问网络或更新正式站。验证记录另存同目录。
