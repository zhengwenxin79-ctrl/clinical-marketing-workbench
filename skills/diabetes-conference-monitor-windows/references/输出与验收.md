# 输出与验收

适用于执行后核对，不要求事先加载整个研究知识库。

|字段或状态|解释|
|---|---|
|`run_id`|本轮实际运行目录编号；回放时可生成新编号，但原检查时间不变|
|`run_status=complete`|全部配置入口均提取出日期等会议信息|
|`run_status=partial`|部分入口解析成功，其余缺口单列|
|`run_status=failed`|没有入口成功解析，不能写成无会议变化|
|`checked`|保存页面并取得可解析日期信息，不代表读完整会议研究|
|`page_only`|取得页面，完整内容仍待核|
|`parse_gap`|日期或页面格式待核|
|`fetch_failed`|请求失败、超时或访问受阻|
|`conflict`|同届官方观察冲突，保留先前信息待复核|
|`events_this_run`|本轮产生的新候选；与草稿累计事件数不同|

固定入口会核对：来源ID集合与数量；包文件和项目构建脚本指纹；正式日历哈希；草稿状态及哈希；运行状态与成功数；会议届次ID及日期先后；每条新观察和变化的官方正文片段；同轮事件去重；HTML/dist/ZIP一致性。collect/replay还核对正式文件和研究数据在执行前后不变。

输出规则：保留原始来源链接和保存正文；首次收录、资料补充与主办方实际变更分开理解。日程入口本身不证明完整日程已经发布。会议元数据不产生Biomarker热点或产品评分。

允许更新的运行数据是项目的`monitoring/runs`、`monitoring/待复核`、state/latest和进程锁。Skill入口不提供正式应用或定时任务操作。源码与规则改动属于维护工作，需要更新包并再验证。
