# 会议收集评级

为吉因加市场部收集六大临床领域下一周或指定日期范围的会议，给出初步关注等级，交付Excel表格，帮助后续优先获取日程、了解临床科研团队。

## 怎么收集

**按组织查 → 按系列追 → 补充搜索 → 核实、去重、汇总。**

两张参考表包含中华医学会、中国医师协会相关的13个主干分会、6个专题补充组织，以及28个会议系列或专题条目。每次运行追查本届最新通知，逐步补充新会议。

关注自免、内分泌、神经精神、心血管、慢阻肺、泛血管。

## 怎么查漏

分别核对中华医学会和中国医师协会的相关组织，再用六大领域的病种和覆盖城市补充搜索。给每个重点系列记录实际检查入口与本轮去向，包括目标周举办、其他时间举办、安排待核实、本届尚未找到或已取消。

重要入口受限时，从本届会议全称、主办方、独立会务站或承办单位补查。“本轮检查说明”区分已查无目标周会议、访问受限和尚未检查。审核发现漏会时补录会议，并将相关组织、渠道或系列作为底表更新建议。

## 六大领域具体查什么

搜索和评级共同使用以下方向，遇到同领域的新病种或交叉研究时结合实际主题判断。

| 领域 | 优先查找的子方向 | 主要科研内容 |
|---|---|---|
| 自免 | 类风湿关节炎、系统性红斑狼疮、干燥综合征、系统性硬化症、血管炎等 | 免疫机制、分型、器官损伤、疗效预测、标志物及队列 |
| 内分泌 | 糖尿病、肥胖及代谢异常、甲状腺相关疾病 | 代谢机制、分型、遗传因素、并发症、治疗反应及随访 |
| 神经精神 | 分别检查认知障碍与阿尔茨海默病、帕金森病、神经免疫，以及抑郁症、双相情感障碍等 | 发病机制、早期识别、分型、标志物、进展与预后 |
| 心血管 | 冠心病、心力衰竭、心肌病、高血压等 | 机制、风险分层、遗传因素、心肌损伤、疗效及预后 |
| 慢阻肺 | 慢阻肺发病机制、急性加重、疾病进展及共病 | 炎症免疫、表型、微生态、早筛、标志物及队列 |
| 泛血管 | 动脉粥样硬化、脑血管疾病、糖尿病血管并发症、肺血管疾病及跨器官血管损伤 | 血管损伤、血栓炎症、风险预测、多器官关联及多中心研究 |

同一会议可保留多个领域标签并合并为一条记录；综合大会注明值得关注的会场。神经精神分别查神经和精神方向，泛血管沿相关疾病和组织交叉寻找。

## 怎么评级

**先确认具体议程 → 按大会主线和主要参会群体定档 → 再看会议级别 → 单独记录科研线索和资料进度。**

从正式通知、参会对象和公开议程判断整场会议价值。重点关注有两个入口。

- **临床科研会议**以目标疾病的机制、临床研究、检测或科研转化为主线，面向相关临床医生、PI或研究团队。
- **检测与组学科研会议**以与吉因加业务直接相关的检测或组学研究为主线，正式议题涵盖疾病研究或临床转化，面向相关科研团队。

| 关注等级 | 判断口径 |
|---|---|
| 重点关注 | 符合临床科研或检测与组学科研任一入口，整场会议值得优先跟进 |
| 常规关注 | 大会整体与目标疾病、检测或临床科研合作有明确交集，参会群体中有值得对接的团队，适合定向了解 |
| 低优先级 | 以康复路径、运动处方、护理、常规病例交流、手术技术、器械应用或操作培训为主的会议，各级别和各城市采用同一口径 |
| 待确认 | 尚未取得具体日程，或已读内容和主要参会群体仍不足以定级，注明待补问题 |

具体日程至少要有能判断大会主线的专场、议题或讲题。仅有会期、报到、“学术交流”等笼统安排或征文方向时，优先级填**待确认**，全国性年会也按同一口径。会期已核实的会议仍在“会议清单”。例如，中华中医药学会脑病分会年会在具体议程待补时保留在主表，优先级填待确认。

已读部分具体日程足以判断大会主线和主要参会群体时，可先定级。代谢组学分会年会属于检测与组学科研入口，读到支持疾病代谢组学方向的具体议程后可按重点关注条件定级。长城心血管疾病预防与康复大会以康复实践为主，列为**低优先级**，心脑互作蛋白代谢组学和双心队列报告单独记入备注。

## 科研专题突出怎么看

具体依据来自正式通知、征文专题、议程和讲题，重点寻找疾病机制、标志物与精准诊疗、队列及多中心研究、临床与基础转化、临床试验及真实世界研究等内容。

结合录音里的业务口径，判断具体临床问题、研究方法及转化场景。优先关注通过临床样本、血液或分子标志物、多组学等开展早筛、分型、疗效或预后研究的专题，说明与检测服务的潜在关联。例如，慢阻肺急性加重专题涉及血液标志物风险预测时，可以用具体讲题说明价值。公开的讲者及研究单位可以辅助判断。

科研内容贯穿主旨报告或多个核心环节时，可作为整场评级依据。科研内容集中在个别讲题或附属专场时，将具体议题及相关团队写入备注，作为定向跟进线索。完整判断规则及示例见 [SKILL.md](SKILL.md)。

## 日程怎么获取

从本届大会官网、主办或承办方渠道寻找日程，读取网页、PDF或长图，核对年份、届次、最新版本和实际读取范围，保存链接或文件位置及获取日期。图片日程结合环境可用的文字识别能力读取；重点会议优先定位相关科研专场，详细人员表交后续客户拆解流程。

| 日程状态 | 含义 |
|---|---|
| 已获取 | 已实际读取本届公开日程，注明版本及覆盖范围 |
| 部分获取 | 已读取部分具体专场、议题或讲题，注明待补范围 |
| 待发布 | 官方明确表示稍后公布 |
| 尚未找到 | 已检查相关入口，本轮尚未找到公开日程 |
| 需人工协助 | 需要登录权限、人工下载或截图，说明所需材料 |

实际读取后记录获取状态，初版日程注明版本。能获取的范围依据WorkBuddy当时可用的浏览、下载和识别能力记录，日程进度单独写入原12列会议表的备注。

## Excel交付

默认交付一个.xlsx工作簿，命名为 `会议收集评级_YYYYMMDD-YYYYMMDD.xlsx`，日期对应收集区间。

| 工作表 | 内容 |
|---|---|
| 会议清单 | 收录会期已核实的会议，含优先级待确认项。沿用12列，按关注等级和日期排序，评级依据、日程状态、来源及待补事项写入备注 |
| 待核实会议 | 有此类会议时建立，保留同一12列表头，说明尚待核实的安排 |
| 本轮检查说明 | 使用“项目｜内容”两列，记录目标日期范围、整理日期、审核状态、已检查范围、核心系列去向、待补查范围、新增线索及同周更新 |

会议表表头置于首行，冻结表头、启用筛选，备注自动换行并保留来源链接。已取得可用日程的重点会议，可在备注中注明交后续客户拆解。

交付前核对日期、重复项、评级依据、日程状态和来源，并打开生成的.xlsx确认文件可读取。审核状态填“待辛小青审核”，后续按工作簿中的待补事项更新。客户拆解、客户深调与客户评级由后续流程承接，审核后再按授权交付BD。交付信息提供Excel文件链接及简短完成确认。

“本轮检查说明”工作表中：

| 项目 | 填写内容 |
|---|---|
| 已检查范围 | 实际检查的领域、组织和主要渠道；注明已检查但未发现目标周会议的范围 |
| 核心系列去向 | 每个重点系列的本轮结果及实际检查入口 |
| 待补查范围 | 未完成检查的组织、受限入口或待读资料，以及下一步路径 |
| 新增线索 | 建议长期关注的新组织或会议系列；无新增时如实说明 |
| 同周更新 | 补查时记录更新日期、受影响会议、变化内容和依据 |

依据当次实际操作填写，区分已检查无目标周会议、访问受限和尚未检查，与参考表的建表信息分开。具体Excel结构见 [SKILL.md](SKILL.md)。

## 同一目标周怎么补查

打开该目标周最近一份Excel，沿用检查说明中的起止日期，即使补查发生在下一自然周。优先补待核实会议、重点会议日程和受限入口，核对最新正式安排并更新同一届会议。安排确认且仍在目标区间的会议移入主表，改期至区间外或取消的会议在检查说明中记录去向。

更新日程版本、来源和读取范围。新证据影响评级时写明变化理由。将更新日期、变化和待补事项记入同一个工作簿，交付该目标周更新后的一个.xlsx。

## 给WorkBuddy的任务

将整个文件夹提供给支持读取本地Skill的环境，保持目录结构；使用时需要搜索、浏览、读取公开会议资料及生成Excel的能力。可以直接发送：

> 请读取“会议收集评级”文件夹中的SKILL.md。使用两张参考表和六大领域子方向收集下一周的会议，分别查中华医学会和中国医师协会，逐项追踪核心会议系列并补充搜索。核实本届会期并查找具体日程。尚未取得足以判断大会主线的具体专场、议题或讲题时，优先级填待确认，会期已核实的仍列入主表。取得具体议程后，按大会主线和主要参会群体判断整场价值，再看会议级别。重点关注包括临床科研会议，以及正式议题涵盖疾病研究或临床转化的检测与组学科研会议。以康复路径、运动处方、护理、常规病例交流、手术技术、器械应用或操作培训为主的会议列为低优先级。有价值的个别讲题或附属科研专场单独记在备注，覆盖城市用于安排同档跟进。优先读取重点会议的日程。交付一个.xlsx，包含12列“会议清单”、按需建立的“待核实会议”和“本轮检查说明”。在备注中写评级依据、日程状态和来源，在检查说明中记录实际检查范围、核心系列去向、补查事项和审核状态。同一目标周补查时，沿用上一份Excel的起止日期，更新同届会议并记录变化。

指定时间时，将“下一周周一至周日”替换为实际起止日期。
