# 会议收集与评级

## 目标与范围

**评级服务于销售现场触达目标客户并建立联系（加微信）。** 一场会议的等级，第一判据是销售能不能在现场见到目标客户、能不能约到人，而不是会议本身的学术规格。帮助市场部找到值得进一步获取日程、了解临床PI及检测、组学等研究团队的会议，形成供辛小青审核的周度Excel会议清单。会议收集和初评依据公开会议信息即可开展，产品资料和客户池可在后续业务中补充。

- 领域：自免、内分泌、神经精神、心血管、慢阻肺、泛血管。神经精神分别覆盖神经内科与精神医学；泛血管交叉关联心血管、脑血管、糖尿病血管并发症及肺血管疾病。“检测与组学”作为横切标签使用，可与任一领域并用标注（如“慢阻肺／检测与组学”），不单独作为一个领域计数。
- 地域：默认国内**线下**举办的会议，含国内举办的国际冠名会议；纯线上、线上直播为主的会议不收录。全国性核心会议全国收集；举办地在10个销售覆盖城市之外的会议不列重点关注。
- 内容：优先寻找六大领域的临床科研会议。检测与组学内容单独记录为备注线索，本身不构成重点关注理由。综合大会的相关专场或讲题单独记录。
- 时间：首次收集时优先使用用户指定日期，默认以北京时间下一自然周周一至周日为范围。同一目标周补查沿用原工作簿的起止日期。会议举办日程与目标区间有重叠即可纳入。通知可能提前数月发布，检索覆盖当年及目标区间涉及的年份。

## 六大领域的搜索与判断方向

搜索和评级共同使用以下子方向口径，结合具体研究问题理解会议相关性。病种名称用于扩展发现，遇到同领域的新病种或交叉研究时结合主题判断，并记录适合补充的方向。

| 领域 | 优先查找的子方向 | 重点识别的科研内容 |
|---|---|---|
| 自免 | 类风湿关节炎、系统性红斑狼疮、干燥综合征、系统性硬化症、血管炎等 | 免疫机制、疾病分型、器官损伤、疗效预测、标志物及队列研究 |
| 内分泌 | 糖尿病、肥胖及代谢异常、甲状腺相关疾病 | 代谢机制、疾病分型、遗传因素、并发症、治疗反应及长期随访 |
| 神经精神 | 分别检查认知障碍与阿尔茨海默病、帕金森病、神经免疫疾病，以及抑郁症、双相情感障碍等 | 发病机制、早期识别、疾病分型、标志物、进展与预后研究 |
| 心血管 | 冠心病、心力衰竭、心肌病、高血压等 | 疾病机制、风险分层、遗传因素、心肌损伤、疗效及预后研究 |
| 慢阻肺 | 慢阻肺发病机制、急性加重、疾病进展及共病 | 炎症与免疫机制、表型分型、微生态、早筛、标志物及队列研究 |
| 泛血管 | 动脉粥样硬化、脑血管疾病、糖尿病血管并发症、肺血管疾病及跨器官血管损伤 | 血管损伤机制、血栓与炎症、风险预测、多器官关联及多中心研究 |

同一会议涉及多个领域时保留交叉标签，合并为一条会议记录。综合大会指出值得关注的专题或会场；神经精神分别寻找神经与精神方向，泛血管沿相关疾病和组织交叉发现。

## 收录边界

以下口径用于在收集阶段初筛、在评级阶段定档。判断顺序：先看是否属于硬性不收录，再看是否属于硬性降档，最后按会议主线与会议身份定级。

### 硬性不收录（不进主表）

| 类型 | 判断要点 | 处理 |
|---|---|---|
| 纯线上会议 | 全程线上直播、网络研讨会、云课堂，无线下会场 | 不收录。无现场接触场景，销售见不到人、加不到微信 |
| 营养代谢类 | 以营养、代谢与机体健康、膳食干预为主线的研讨会 | 整类不收录 |
| 中医药思想流派 | 名医学术思想研讨、流派传承、经典理论研修等附设或主体内容 | 不收录。**中医药病种与临床诊疗会议仍然收录**，按临床科研主线正常定级 |
| 英文论文演讲与竞赛 | 中青年英文演讲比赛、论文竞赛、优秀论文汇报为主的交流活动 | 不收录。属学术训练场景，客户密度与业务关联低 |
| 纯继教培训班 | 以学分授予、规范化培训、操作培训为主的班次 | 不收录或列低优先级，以是否含科研议题为准 |
| 非六大领域专科 | 消化内镜、肝胆胰外科、灸法等技术类方向 | 不收录 |

### 硬性降档（最高到低优先级）

| 类型 | 判断要点 | 处理 |
|---|---|---|
| 检验、医学遗传、分子诊断 | 主线为检验质量管理、实验室能力建设、遗传检测、分子诊断技术 | 最高定到低优先级。**不因整场是检测主线而升重点** |
| 诊断技术开发类 | 诊断技术开发者大会、技术平台发布、试剂与仪器开发 | 最高到低优先级；纯技术开发的可移出主表 |
| 组学方法学类 | 代谢组学、蛋白质组学、多组学方法论坛，以方法、平台、生信分析为主线 | 最高到低优先级。含明确疾病临床转化专场的保留收录，在备注写明该专场，但仍不升档 |
| 外科与手术技术 | 以手术技术、术式演示、器械应用、介入操作演示为主 | 低优先级。含基础研究或转化医学内容的，仅记录专场线索 |
| 康复、护理、基层下沉 | 以康复路径、运动处方、护理规范、基层能力建设为主 | 低优先级 |

判断“是方法学还是临床科研”的分界：整场以**疾病机制、诊断分型、疗效预测、队列与临床研究**为主线，属临床科研；整场以**怎么测、测得准不准、用什么平台测**为主线，属方法学或检验。两者交织时，看主旨报告与大会主题落在哪一侧。

检测与组学类会议中含临床转化内容时**保留但不升档**：保留是为了留线索，不升档是因为这类会议的主要参会群体是检验科、方法学研究者，与销售要触达的临床科室客户重叠有限。是否派人由销售按属地自行判断。

### 病种偏好

以下为当前业务偏好，随业务调整，调整后同步更新本节并在“本轮检查说明”记录变更日期：

- **肺动脉高压：重点方向。** 同场会议同时包含先心病与肺动脉高压时，只投肺动脉高压专场，先心病专场不派人，备注写明分工。
- **先心病：关注度低。** 见上条。
- 其余病种按六大领域子方向表判断。

### 人工指定优先

用户明确指定某场会议的等级时，按指定执行，不受上述边界约束。在备注写“人工定级（日期）：用户指定为X，理由…”，保留原评级依据原文不删。人工指定不代表边界失效，其余会议仍按边界执行。

## 四步收集流程

### 1. 按组织查

读取 [组织与渠道表](references/组织与渠道表.md)，分别检查中华医学会、中国医师协会相关分会及专题组织。

结合总会年度计划、分会官网或公众号、会议平台、当届承办单位通知寻找会议。年度计划查看全国大会、专病及中青年会议等相关章节，包含月份待定的条目。图像、PDF或动态页面用可用的浏览、截图或识别工具读取。

组织检索同时使用“组织全称＋子方向＋年份＋会议通知/年会/学术会议”等适合的组合，并通过开放搜索寻找委托会务站和独立域名。入口受限时，尝试组织全称、会议全称或承办单位等替代路径，记录仍需补查的部分。

### 2. 按系列追

读取 [核心会议系列表](references/核心会议系列表.md)，逐项查找本届通知，覆盖全国主年会及独立专病会议。

使用标准名称、名称变体或简称寻找本届入口。表中的2026年入口用于定位系列；其他年份运行时追查对应届次，使用本届实际公布的安排。

查到系列后，明确其本轮去向：目标周举办、其他时间举办、安排待核实、本届暂未找到或已取消。仅有旧届资料时保留本届待查事项。重复使用第一步已核实的材料即可。

### 3. 补充搜索

**本步必须逐项执行，不得只朝一个方向搜。** 漏检的主要来源就是这一步被简化。按下表逐条跑，每条至少在“本轮检查说明”里留下一句结果，写明已查未发现或访问受限：

| 检查项 | 检索式组合 | 说明 |
|---|---|---|
| 六大领域逐领域 | 领域病种＋“年会/学术会议/大会/论坛/征文/会议通知”＋目标月份 | 六个领域各跑一轮，不得合并成一次搜索 |
| 覆盖城市逐城市 | 城市名＋领域病种＋目标月份；城市＋医学会/医师协会/核心医院 | 10个城市各跑一轮，重点城市（北京、上海、广州、杭州、成都）优先 |
| 检测与组学方向 | “疾病代谢组学＋年会”“分子诊断＋学术会议”“队列＋组学＋论坛” | 找到的按“收录边界”处理，作为备注线索或不收录留档 |
| 会议品牌与独立域名 | 已知系列简称＋年份；委托会务站域名 | 用于发现底表之外的会议 |

围绕六大领域的病种和子方向，结合“年会、学术会议、大会、论坛、征文、会议通知”等词补充检索，发现底表之外的新组织、医院会议和会议品牌。区域会议结合覆盖城市及当地医学会、医师协会、核心医院寻找。

同时从检测和组学研究方向补查相关学会与年会，例如以“疾病代谢组学＋年会”检索，查看正式议题中的疾病研究或临床转化内容。这类会议按“收录边界”定档，不列重点关注，但需收录或留档，避免下周重复查。

第三方日历、专科媒体和公众号用于发现线索，再追查原始通知，不得直接作为入表依据。适合长期关注的新组织或会议系列，作为底表补充建议记录在Excel的“本轮检查说明”工作表中。

### 4. 核实、去重并汇总

- 优先用本届最新正式通知、更正通知或大会官网更新核实名称、主办方、日期和地点，检查延期或改址信息。会务平台上的正式通知可作为依据，核对其中明确的主办关系。
- 年度计划、继教目录、采购公告和第三方日历提供发现线索；仅有计划资料时写“计划时间/地点，待正式通知核实”。来源冲突时核对同届信息和有效更新，未解决的冲突写清楚。
- 按“会议系列＋年份/届次＋主办身份”识别同一场会议，合并各渠道来源。日期或城市更新仍归同届；联合会议保留完整名称，分会场归入所属大会并注明专题。
- 正式安排与目标周重叠的进入“会议清单”工作表；可能涉及目标周但安排待核的会议，使用同一表头列入“待核实会议”工作表。明确改期至其他日期的记录在“本轮检查说明”的后续补查事项中。
- 基本信息已发布时先收录；日程按下方流程获取并记录进度，人数、会务联系人等未查到写“待确认”。参会人数注明预计、报名或实际口径；讲者数量与完整参会人数分别理解。
- 日期已过时，通过正式会后报道等资料确认举办情况；仅有计划日期则写“计划日期已过，举办状态待核实”。

## 日程获取与进度

对已收录会议查找本届日程。具体日程指正式材料已列出可辨认内容的专场、议题或讲题，能据此判断大会主线。会议日期、报到时间、“学术交流”等笼统安排和征文方向用于记录会议信息及引导补查。尚未取得足以判断主线的具体日程时，优先级填“待确认”。

1. **找本届入口：**检查大会官网中的“会议日程、详细日程、资料下载、会议通知”等栏目，结合主办方、承办方官网及公众号寻找正式日程。
2. **读取公开内容：**网页日程按日期、会场或专题读取；PDF下载后读取，扫描PDF和长图通过可用的文字识别或截图工具提取。需要登录、人工下载或截图时，明确需要补充的材料。
3. **核对版本与范围：**核对年份、届次、发布或更新日期，使用本届最新有效版本。记录实际读到的日期、会场或页码；大日程可分段读取，注明已读及待补范围。初版日程注明版本，后续关注更新。
4. **保存并交接：**保留日程链接或已获取的文件位置、获取日期和重点科研专题。可读取的时间、会场、讲题、讲者及单位用于说明专题依据；详细人员表交后续客户拆解流程。

| 日程状态 | 使用条件与记录内容 |
|---|---|
| 已获取 | 已实际读取本届公开日程，注明版本、覆盖范围及链接或文件位置；已公布范围读完但仍为初版时，标明“初版” |
| 部分获取 | 已读取部分具体专场、议题或讲题，说明已读内容与待补范围 |
| 待发布 | 官方明确表示日程稍后公布，记录相应通知和复查事项 |
| 尚未找到 | 本轮已检查相关入口，仍未找到公开日程，简述已检查路径及下一步 |
| 需人工协助 | 获取需要登录权限、人工下载或截图，记录入口及所需材料 |

实际读到具体议程后记录“已获取”或“部分获取”。仅有会期或学术交流时段时，按实际情况记录“待发布”“尚未找到”或“需人工协助”，并在备注写明补查路径。

## 初步评级

判断整场会议是否值得优先获取日程、进一步了解相关临床或科研团队。采用四个关注等级，用1—2句话解释评级依据。

### 按顺序判断

1. **先确认具体议程，再判断整场大会的主线和主要参会群体。** 结合已读具体议程和正式通知判断业务相关性。病种关键词用于标记领域。尚未取得具体日程，或已读内容仍不足以判断主线与主要参会群体时，优先级填“待确认”并记录待补项。全国性年会也按此口径执行。
2. **按业务相关性定档，再看会议级别。** 第一判据是销售能否现场触达目标客户：线下举办、举办地在10个覆盖城市内、参会人群为临床医生、科主任、检验负责人等目标客户、会期有展位、会务、茶歇、卫星会等可接触场景。三项同时满足且符合下方重点关注条件的会议可列为重点关注。正式全国性学会或分会年会身份、核心专病定位和主议程中的科研内容可支持重点评级。规模作为辅助参考；覆盖城市用于安排同档会议的跟进顺序，异地举办同时触发降档。
3. **单独记录科研专场或讲题。** 相关研究集中在个别报告或附属专场时，将讲题、研究问题和可识别的团队写入备注，整场等级继续按大会主线和主要参会群体判断。
4. **单独记录资料进度。** 已读部分具体日程足以判断大会主线和主要参会群体时，可以先定级，后续补齐其余讲题、人数和讲者名单。

### 重点关注的条件

以下条件需同时满足，任一不满足即不能列重点关注：

- **疾病领域临床科研主线。** 大会以目标疾病的机制、临床研究、检测的临床转化或科研转化为主线，主要面向相关临床医生、PI或研究团队。围绕专病或明确科研问题的主要议程可作为依据。
- **覆盖城市内。** 举办地在10个销售覆盖城市之内。异地举办的全国性年会可列常规关注并注明差旅成本。
- **线下且可触达。** 线下举办，会期有展位、会务对接、茶歇、卫星会等可接触场景。纯线上不收录。

**检测与组学内容不单独构成重点理由。** 以检测、医学遗传、分子诊断、组学方法学、诊断技术开发为主线的会议，按“收录边界”最高定到低优先级。这类会议的价值写在备注里作为跟进线索，不改变整场等级。会前培训、厂商展示等附属活动同样单独记录。

### 关注等级

| 等级 | 判断依据 |
|---|---|
| 重点关注 | 同时满足疾病领域临床科研主线、覆盖城市内、线下可触达三项条件，整场会议值得优先跟进。备注写明大会主线、主要参会群体、可接触场景和证据 |
| 常规关注 | 大会整体与目标疾病、检测或临床科研合作有明确交集，参会群体中有值得对接的团队，适合定向了解；或属重点条件的会议但举办地在覆盖城市外 |
| 低优先级 | 检验、医学遗传、分子诊断、组学方法学、诊断技术开发类会议；以康复路径、运动处方、护理、常规病例交流等实践为主；以手术技术、器械应用、操作培训为主；面向基层下沉的小会。各级别和各城市采用同一口径，有价值的研究线索写入备注 |
| 待确认 | 尚未取得具体日程，或已读内容、正式身份、主要参会群体等关键信息仍不足以支持定级，说明应补充什么 |

以正式资料核实全国性年会身份，标题中的“全国”可作为补查线索。交付时写清评级对应的整场依据，以及具体讲题的独立价值。

### 怎样判断相关科研专题突出

从正式通知、征文专题、议程或讲题中找到具体证据，说明研究问题以及与临床科研合作的关系。优先识别以下内容：

| 科研方向 | 可观察的会议内容 |
|---|---|
| 疾病机制 | 免疫机制、炎症通路、细胞功能、遗传因素、疾病发生发展机制 |
| 标志物与精准诊疗 | 早筛、疾病分型、疗效或预后预测，以及相关标志物研究 |
| 队列与多中心研究 | 队列随访、多中心项目、研究结果发布或研究方案讨论 |
| 临床与基础转化 | 临床样本研究、机制验证、分子分型、多组学与临床问题结合 |
| 临床研究 | 临床试验、研究设计、真实世界研究、治疗反应差异 |

判断专题业务价值时，结合录音提到的临床问题、科研和转化三个方面。先指出具体疾病或临床问题，再看研究如何使用临床样本、血液或分子标志物、多组学等方法，以及是否面向早筛、分型、疗效预测、预后评估或其他可说明的检测与转化场景。按公开材料说明与吉因加检测服务的潜在关联，产品资料可在后续合作评估时补充。

例如，围绕慢阻肺急性加重，使用血液标志物开展风险预测的专场，可以用“急性加重风险预测＋血液标志物研究”说明相关性。综合会、行为或心身医学等交叉会议，依据具体议题判断业务价值。已公开的讲者、单位及核心医院或研究团队参与线索，可辅助判断该专题是否值得进一步了解。

再判断相关内容在会议中的分量：

- **会议定位突出：**会议本身围绕明确的相关科研问题展开，可依据正式定位和议题判断科研特色。
- **专场突出：**科研内容集中在某个专场时，在备注记录专场名称、代表议题和研究团队，作为定向跟进线索。
- **主要议程突出：**相关机制、队列、检测或临床研究成果贯穿主旨报告或多个核心环节时，结合主要参会群体判断整场价值。
- **个别报告相关：**将具体讲题及其价值单独记入备注，整场会议仍按大会主线和主要参会群体评级。
- **宣传线索待补：**“前沿、创新、精准”等概括性表述用于继续查找具体议题，先按已确认的会议身份和内容评级。

具体讲题、专场安排和研究项目名称是直接依据；公开讲者及单位可辅助定位研究团队。初评基于公开日程提供研究团队线索，逐人的基金、论文和产品需求调研留给后续流程。

以会议关注等级决定取日程和了解研究团队的优先顺序。属地小会可在备注中提示销售选择性查看，实际参会结合人员安排和差旅投入另行判断。

评级示例

- 重点关注：全国性认知障碍专病年会面向相关临床与科研团队，已读日程列有痴呆队列、血液标志物等研究议题，举办地在覆盖城市内，设展位并开放卫星会报名。
- 重点关注不成立（异地）：同性质的全国专病年会若在大连、贵阳等覆盖城市外举办，降为常规关注，备注注明需专程差旅、建议选择性参会。
- 低优先级：中国生物物理学会代谢组学分会年会以组学方法学交流为主，虽含疾病代谢组学议题，按收录边界不定为重点，将相关专场写入备注作为跟进线索。
- 低优先级：全国检验医学学术会议主线为检验质量管理与实验室能力建设，业务有交集但非疾病临床科研主线，定低优先级；含临床转化的分会场在备注注明。
- 不收录：某神经免疫抗体专题研讨会为线上直播、无现场接触场景，销售无法触达，移入“已检查未纳入”并留档。
- 常规关注：区域呼吸会议面向呼吸科临床团队，正式议题包括慢阻肺长期随访和区域队列交流，适合定向了解相关团队。
- 低优先级：长城心血管疾病预防与康复大会以心肺康复实践为主，主要面向康复医护和专委会委员，心脑互作蛋白代谢组学和双心队列报告单独记入备注。
- 低优先级：全国性神经外科年会，主要面向神经外科医生，议程以手术技术、内镜或介入操作为主；脑血管病标志物研究讲题单独记入备注。
- 待确认：中华中医药学会脑病分会年会已核实会期，通知列有学术交流日期和征文方向，具体专场、议题或讲题待补。保留在“会议清单”，优先级填“待确认”。

## Excel交付

默认交付一个Excel工作簿（.xlsx），文件名为 `会议收集评级_YYYYMMDD-YYYYMMDD.xlsx`，日期对应目标区间。交付信息提供文件链接及简短完成确认，评级、日程和检查信息集中保存在工作簿内。

“会议清单”和“待核实会议”沿用12列表头，优先级按“重点关注、常规关注、低优先级、待确认”排序，同级按会议日期排序，各表序号连续：

`序号｜领域大类｜疾病方向｜会议名称｜会议时间｜会议地点｜会期｜参会人数｜联系人｜状态｜优先级｜备注`

- 备注按“评级依据＋重点科研专题＋日程状态＋可接触场景＋来源＋会议链接”说明，带上主办方及必要待核项；日程可注明版本、读取范围、链接或文件位置及获取日期。记录关键来源的发布/更新日期，未标日期时如实说明。日程状态写在备注中，保留12列表头。
- **每行必须附会议链接，放在备注最后一行，以“链接：”开头**，便于人工查验。多个链接用“；”分隔，取主办方官网、学会通知原文、会议官方微站、承办单位发布页的优先顺序；同一会议不同页面的链接不超过3条。链接未定位时写“链接：未定位”，不得编造或使用搜索页、聚合页充当官网。
- 可接触场景写明是否设展位、是否开放招商或卫星会、是否需注册费、会务联系人是否可对接，便于销售判断能否约到人。
- 事实使用已读取材料明确支持的信息；PI参与情况区分拟邀、日程列名与实际参会，会务联系人填写公开会务信息。
- 每行对应一场会议，表头置于首行，冻结表头并启用筛选；备注自动换行，链接保留为可追溯的网址或超链接。

### 工作表结构

| 工作表 | 内容 |
|---|---|
| 会议清单 | 会期已核实且与目标区间重叠的会议，含优先级待确认的会议，保留12列；重点专题、日程状态、来源及会议级待补事项写入备注 |
| 待核实会议 | 有可能涉及目标区间、安排仍待核实的会议，使用同一12列表头；有此类会议时建立 |
| 已检查未纳入 | 已核实会期地点、但按“收录边界”不收录或不在覆盖城市的会议，列会议名称、会期、地点、不纳入原因；本轮无此类会议时可不建 |
| 已删除会议 | 曾收录后按口径移出主表的会议，列原序号、会议名称、原优先级、会期、地点、删除原因；用于留档与避免重复收录 |
| 本轮检查说明 | 使用“项目｜内容”两列记录目标日期范围、整理日期、审核状态、实际检查范围、核心系列去向、收录边界执行情况、待补查范围、新增线索及同周更新情况 |

“本轮检查说明”按以下内容填写：

| 项目 | 内容要求 |
|---|---|
| 目标日期范围 | 本轮会议收集的起止日期 |
| 整理日期 | 本次实际整理或更新日期 |
| 审核状态 | 待辛小青审核 |
| 已检查范围 | 实际检查的领域、组织及主要渠道，说明已检查但未发现目标周会议的范围 |
| 核心系列去向 | 每个重点系列的本轮去向及检查入口，可按系列逐行填写 |
| 收录边界执行情况 | 写明本轮按边界排除或降档的会议数量与名称，例如纯线上几场、营养代谢几场、检验遗传诊断几场降至低优先级、覆盖城市外几场降档；无则写“本轮无触发” |
| 待补查范围 | 未完成检查的组织、受限入口、待读日程，以及具体补查路径或复查时间 |
| 新增线索 | 建议长期关注的新组织或会议系列，无新增时如实说明 |
| 同周更新 | 补查时记录更新日期、受影响会议、变化内容及依据，首次收集可省略 |

检查说明以本轮实际访问和检索为依据，区分“已检查未发现目标周会议”“访问受限”和“尚未检查”，并与参考表的建表核对信息区分。有可用日程的重点会议，在备注中注明可交后续客户拆解。

### 交付前查漏

1. 对照组织与渠道表，分别核对中华医学会、中国医师协会的相关组织和入口，再核对六大领域的补充搜索是否实际执行。遇到入口受限或重要系列未定位，优先按会议全称、年份或届次，从主办方通知、独立会务站、承办单位等路径补查。
2. 对照核心会议系列表，为每个重点系列在“本轮检查说明”中记录实际检查入口和本轮去向，例如目标周举办、其他时间举办、安排待核实、本届尚未找到或已取消。入口受限、尚未检查或只读取部分资料时，注明实际进度和下一步路径。
3. 对照确认结果和工作簿，目标周已核实会议进入主表，可能在目标周的待核会议进入待核实表。对已检查但未发现目标周会议的范围，明确写出检查结果。审核中发现的漏会，补录本届记录并提出组织、渠道或系列的更新建议。
4. 对照“收录边界”复核主表：是否混入纯线上、营养代谢、中医药思想流派、英文论文演讲、非六大领域专科的会议；检验遗传诊断与组学方法学类是否被误列重点关注；举办地在覆盖城市外的会议是否仍列重点关注。被移出的会议须在“已检查未纳入”或“已删除会议”留有记录。
5. 逐行检查备注最后一行是否为“链接：”，并确认链接指向主办方官网、学会通知、会议微站或承办单位页面；未定位的写“未定位”，不得以搜索页或聚合页顶替。同时确认排序为重点关注→常规关注→低优先级→待确认，同级按会议日期，各表序号连续。

### 完成本轮交付

交付前快速核对：目标周与最新安排一致、同届会议已合并、评级体现大会主线和主要参会群体及可触达性、每行备注附有会议链接、日程状态符合实际读取范围、来源及待补信息清楚、按收录边界该排除的已排除。打开生成的.xlsx核对工作表和数据，确认文件可读取且内容完整。

完成Excel会议表及检查说明后，标记为“待辛小青审核”，本轮收集评级工作即可交付。按已核实的依据先交付评级，日程等待补项留在工作簿内。

## 同一目标周补查

1. 读取该目标周最近一份Excel，从“本轮检查说明”取得原起止日期和待补事项。跨周补跑时继续用原区间。原表暂不可用时，按用户明确提供的目标日期继续，或先确认原区间。
2. 优先追查待核实会议、重点会议日程和受限入口，检查新发布的正式通知与改期、取消、改址信息。查到漏会时按同一目标区间纳入。
3. 按会议系列、年份或届次和主办身份更新同一条记录。正式安排确认且与目标区间重叠时，将会议归入主表。安排仍待核且可能涉及目标区间的，归入待核实表。改期至区间外或取消的会议移出两张会议表，在检查说明记录去向和来源。已读日程注明最新版本及读取范围。
4. 日程或人数等资料补齐时更新备注。新证据改变对大会主线、主要参会群体或科研价值的判断时，按初评规则重评并说明变化理由。检查说明保留前次已核实记录并注明本次复查结果，包括日期、来源、会议变化和待补事项。交付该目标周更新后的一个Excel工作簿。

## 工作节奏与交接

周四或周五先形成下一周概览。优先级因日程待补而待确认的会议，以及已定级但仍需补重点讲题的会议，列为后续1—2天复查事项。实际定时跟进以运行环境已配置的能力为准。

本 Skill 完成会议收集与初评。详细参会人员拆解、客户深调和客户评级交给后续流程。输出交辛小青审核，审核后再按用户授权进入BD交付或推送。
