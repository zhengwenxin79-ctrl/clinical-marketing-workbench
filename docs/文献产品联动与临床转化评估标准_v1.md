# 文献产品联动与临床转化评估标准（v1.0）

> **适用范围**：临床科研智能营销工作台（市场部主台 `workbench/领域工作台/index.html`）中的「🧬 吉因加核心产品最新应用文献」模块，以及「会议详情 / 热点议题」弹窗中的「📄 关联最新临床转化文献（Top 3）」联动模块。  
> **生效日期**：2026-11-26  
> **核心代码落点**：`workbench/领域工作台/src/app.js`（`allProductLiterature`、`getRelatedLiteratureForTopic`、`getRelatedLiteratureForConf`、`getLitExternalUrl`）与 `workbench/领域工作台/src/template.html`（`showLitDetailModal`）。

---

## 一、临床转化文献 ↔ 吉因加产品应用联动评估标准

每篇入库文献（涵盖底库 `marketing.db` 160 篇主池文献、精选最新顶刊、以及通过 CodeBuddy CLI 实时抓取的文献）均按以下两层规则进行产品应用标定：

### 1.1 五大核心产品技术标签映射（`productTags`）

系统基于文献的**标题、摘要、所属议题**进行关键词匹配，将文献映射至吉因加非肿瘤核心技术平台（允许一篇文献同时命中多个产品标签）：

| 吉因加产品 / 技术平台 | 核心识别关键词 | 典型临床转化场景 |
| :--- | :--- | :--- |
| **cfRNA / 外泌体** | `cfRNA`、游离 RNA、外泌体、血浆转录组、液体活检 | 神经退行性疾病（AD/PD）、脑卒中、心衰/泛血管损伤无创早筛与动态监测 |
| **GM-seq 甲基化** | `GM-seq`、甲基化、`5mC`、`cfDNA` 甲基化、`CHIP` / 克隆性造血 | 糖尿病肾病（DKD）、血管衰老、心脑血管高危人群早筛与风险分层 |
| **单细胞测序** | `scRNA-seq`、单细胞、`PBMC` 免疫亚群、单核测序 | 自免疾病（SLE/RA）、慢阻肺（COPD）、急性卒中免疫微环境解析与分型 |
| **Stereo-seq 时空组学** | `Stereo-seq`、空间转录组、时空组学、组织微环境空间图谱 | 动脉粥样硬化斑块、纤维化/器官损伤原位空间病理机制研究 |
| **免疫组库 V(D)J** | `V(D)J`、`TCR`、`BCR`、免疫组库、克隆扩增 | 自身免疫病、神经免疫、感染后免疫失衡的受体谱特征与疗效预测 |

### 1.2 应用类型区分（`appType`）

- **临床转化应用**：已进入临床患者队列验证阶段，明确产出早筛、分子分型、预后预测或疗效监测生物标志物，可直接作为销售与临床 PI 切入科研转化/队列合作的话术依据。
- **科研机制发现**：以细胞亚群、信号通路、空间微环境或分子靶点机制揭示为主，适合作为高分论文方向探讨与上游探索性合作切入点。

## 二、会议 / 热点议题 ↔ 文献关联评估模型（4 层打分 + 领域硬护栏）

当用户在工作台打开任意**会议详情弹窗**或**会议热点议题弹窗**时，系统调用 `getRelatedLiteratureForTopic(tp)` 对全量产品文献池逐篇评分，过滤后按总分降序取 **Top 3** 展示。

### 2.1 四层打分明细

| 评估维度 | 分值权重 | 判定规则 | 设计目的 |
| :--- | :---: | :--- | :--- |
| **① 同底库精确议题** | **`+100 分`** | 文献在 `marketing.db` 中的 `topic_id` 与当前议题 ID 完全一致 | 保证数据库原始学术血缘关系的最高优先级 |
| **② 同专科领域（硬护栏）** | **`+20 分`** | 会议/议题与文献同属六大领域之一（糖尿病与代谢、神经精神、呼吸慢病、风湿免疫、心血管、泛血管及器官损伤） | **硬性防误关联约束**：若既不满足维度 ①，又不满足维度 ②，则直接判定 **`0 分` 淘汰**，严禁跨领域文献渗入 |
| **③ 病种 / 技术关键词共现** | **`+15 分 / 词`** | 会议/议题文本与文献文本同时命中核心病种词（如卒中、脑血管、阿尔茨海默、帕金森、COPD、SLE、类风湿、DKD、泛血管、斑块、心衰、肺动脉高压等）或技术词（如 cfRNA、外泌体、甲基化、GM-seq、CHIP、单细胞、时空、V(D)J 等） | 精准放大同领域下“同病种”或“同技术路线”的强业务相关性 |
| **④ 转化价值与时效加权** | **`+5 分` / `+3 分`** | 属于「临床转化应用」加 `+5 分`；属于近 7 天最新文献（`isWeekly = true`）加 `+3 分` | 同等相关度下，优先把更具临床转化落地价值与最新时效的文献排到 Top 3 |

> **入围门槛**：总分 `< 20` 的文献直接过滤，不进入 Top 3 展示。

### 2.2 联动强度三级标签（前端透明可见）

系统会为每条入围的关联文献自动生成 `matchLevel`（强度徽章）与 `matchReason`（具体依据），直接展示在会议/议题弹窗卡片和文献详情弹窗中：

| 联动强度等级（`matchLevel`） | 触发条件 | 界面展示的联动依据示例（`matchReason`） |
| :--- | :--- | :--- |
| **`强关联 · 同底库议题`** | 命中维度 ①（`isExactTopic = true`） | `同底库精确议题 + 同属【糖尿病与代谢】 + 共现【dkd / 甲基化】` |
| **`高相关 · 同领域+病种/技术命中`** | 未命中维度 ①，但命中维度 ② + 至少 1 个维度 ③ 共现词 | `同属【神经精神】 + 共现【单细胞 / 卒中】` |
| **`同领域参考`** | 仅命中维度 ②（同专科领域，无具体病种/技术词共现） | `同属【神经精神】` |

## 三、临床转化阶段评估标准（3 级判定与主导阶段聚合）

### 3.1 单篇文献转化阶段（`stage`）

每篇文献依据其研究成熟度与临床贴近程度划分为 3 个阶段：

1. **早筛转化应用**：已有无创液体活检早筛、伴随诊断或临床检验落地指向（典型如血浆 cfRNA、GM-seq 甲基化早筛模型）。
2. **多中心队列验证**：已在真实临床患者队列中完成生物标志物分型、预后预测或疗效分层验证（最适合切入多中心临床队列合作）。
3. **科研机制发现**：以单细胞测序、时空组学或免疫组库探索疾病发生发展机制与潜在靶点为主，处于临床转化上游阶段。

### 3.2 会议 / 议题整体转化阶段汇总（`stageSummary`）

- **主导阶段判定**：统计该会议/议题 Top 3 关联文献的 `stage` 分布，取出现频次最高的阶段作为该会议/议题的**主导临床转化阶段徽章**（若无命中则默认显示 `临床转化与队列验证期`）。
- **推荐切入产品聚合（`recommendedProducts`）**：聚合 Top 3 关联文献的 `productTags`（去重取前 3 个），渲染为可点击的 `🧬 产品名 →` 快捷按钮，支持一键跳转至对应产品的应用文献池。

## 四、文献详情打开与外链兜底规范

- **站内详情优先**：点击任意文献标题、`查看详情 →` 或会议/议题弹窗内的关联文献卡片，统一唤起 `showLitDetailModal`（层级 `z-[60]`，支持叠加在 `z-50` 的会议/议题弹窗之上），完整展示期刊、PMID、作者、摘要、联动评估依据与可一键复制的销售切入话术。
- **外部原文兜底链（`getLitExternalUrl`）**：按 `detailUrl` → `sourceUrl` → `https://pubmed.ncbi.nlm.nih.gov/{pmid}/` → `https://pubmed.ncbi.nlm.nih.gov/?term={title}` 依次降级，确保任意文献均具备可打开的有效原文/检索链接。

## 五、后续二次调优参考入口

如需调整评估严格度，可直接修改 `workbench/领域工作台/src/app.js` 中 `getRelatedLiteratureForTopic()`（约第 2585–2652 行）：
- **更严格模式（隐藏纯同领域参考）**：将过滤阈值从 `x.score >= 20` 提高至 `x.score >= 35`（即要求同领域且至少共现 1 个病种/技术词，或同底库议题）。
- **扩展词表**：在 `terms` 数组中增补细分病种词（如 `房颤`、`糖网`、`肌少症`、`特发性肺纤维化` 等）或新产品平台关键词。
- **新增评分维度**：可在 `scored` 计算中追加 `同讲者 PI 命中 (+30)` 或 `期刊影响因子加权` 规则。
- 修改后执行 `python -X utf8 tools/export_pages.py` 与 `python -X utf8 tools/test_regression.py` 完成构建与回归验证。
