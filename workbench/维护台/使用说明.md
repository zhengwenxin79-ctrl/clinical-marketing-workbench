# 数据库维护台

维护顺序：**导入资料 → 查看变化 → 确认更新 → 核验导出**。

## 打开

Mac双击数据中心根目录的 `启动数据库维护台.command`，再打开终端显示的 **http://127.0.0.1:8789/**。维护台需要Python 3.9或以上版本，只在本机运行。关闭启动终端或按Ctrl+C即可停止；没有安装自启或定时采集。

Windows安装Python后，可双击 `启动数据库维护台.bat`。Windows启动方式已提供，本轮在Mac验证。

端口被占用时，在数据中心目录运行：

```sh
python3 脚本/启动维护台.py --port 8790
```

维护页面通过本机Python服务读写数据库；直接双击 `维护台/index.html` 无法执行数据库操作。导出的 `会议视图/index.html` 仍可离线查看。

## 四个入口

| 入口 | 操作 | 保存什么 |
| --- | --- | --- |
| 导入资料 | 上传CDS日程JSON，或点击“用已有CDS资料试跑” | 上传原字节、原文件名、SHA256、说明、资料日期、格式失败原因 |
| 查看变化 | 看范围、变更前后及待核问题 | 完整变化清单、原资料定位、比对时数据库指纹 |
| 确认更新 | 查看差异后勾选确认；先备份，再整批提交 | 确认前一致性数据库备份；数据库内批次、字段前后值、来源及确认记录 |
| 核验导出 | 检查数据库、原资料、统计和网页后生成导出 | 每次核验结果、新导出快照、导出前网页备份、文件指纹 |

每批记录在 `维护记录/批次/CDS-…/`。网页左侧可选最近批次，并下载整批资料。列表显示最近50批，目录中的历史记录不会自动删除。操作日志使用连续指纹检查，帮助发现意外改动；本机文件仍需要正常备份，不能把日志视为不可篡改存储。

## 首版能更新什么

输入采用已有 `CDS_全日程结构化.json` 格式，页面可下载样例：顶层为 `as_of`、`sessions`、`items`。原始HTML/PDF继续保存在原始资料目录；若要从新HTML/PDF更新事实，需先形成这个结构化格式。本轮没有增加自动采集、自动文档解析或其他会议的导入器。

- 可确认：已有CDS场次与日程的日期、时间、会场；日期须在本届已知会议范围内。
- 需另行复核：新增/缺少日程、题名、讲者、主持人、场次归属、来源地址和未知字段变化。出现这类问题时整批暂停，原件与问题清单均保留。
- 不改：讲者分层、议题分类、Biomarker判断、科研结果、业务评分。日程有变不等于这些分析可自动更新。

已有正式报告编号用于匹配。无编号日程按场次、类型、题名和原文人物匹配；不能唯一匹配就停止。纯调整输入顺序不会产生覆盖。上传只表示本地收到资料，来源真实性仍需人工核实。

相同资料再次导入会新建一份核对记录，但不会复制业务报告。对同批次重复确认不会再次写入。导入后如果数据库已变化，必须重新导入生成最新差异，避免覆盖他人的更新。

## 核验与导出范围

核验包含SQLite完整性/外键、全部数据库来源文件SHA256、原始436份资料指纹、797条日程和148个场次原文回读、当前议题统计分母、网页/JSON与数据库及文件指纹一致性。

导出的是**当前已确认数据库**，不是重放所选历史批次。当前会议导出器支持CDS首轮606报告、58议题和12板块；需要新增/删除报告或分析版本变化时，应先调整分类与导出器的验收范围。

未通过核验时不替换旧网页。数据库确认与网页导出是两个步骤：数据库已经确认，但导出失败时，先查看记录解决原因，再重试“核验导出”，不重复确认或自行还原数据库。

每次导出保留旧版文件并逐文件原子替换；替换失败会尝试回退。本机三个导出文件不属于数据库事务，运行中断时可从本批“导出前网页备份”恢复后重新导出。当前不提供多人同时在线访问或自动发布。

## 备份和维护

确认前备份保存在 `备份/维护台/…-确认前.db`，通过SQLite备份接口生成。请定期把**整个数据中心目录**复制到另一处受控存储，数据库、原始资料、维护记录和导出须一起保留；单独拷数据库会丢失证据文件。

不提供一键回滚按钮，避免回退旧批次时覆盖其后更新。确需恢复时，先关闭维护台与其他写库程序，备份当前整个目录，核对恢复文件及其后批次，再恢复数据库并重新核验导出。

本次新增3张审计表：`maintenance_runs`、`maintenance_changes`、`maintenance_events`；确认后 `PRAGMA user_version=4`（若已有更高版本则保留）。事实和分析原表结构不变。导入草稿和各次核验日志在文件中；数据库确认与字段审计在同一事务中提交。

## 命令行与回归检查

```sh
python3 脚本/维护数据库.py status
python3 脚本/维护数据库.py import-sample
python3 脚本/维护数据库.py diff CDS-批次编号
python3 脚本/维护数据库.py confirm CDS-批次编号 --actor 本人
python3 脚本/维护数据库.py verify-export CDS-批次编号
python3 脚本/测试维护流程.py
```

`import` 子命令也可接收本地JSON文件。测试只操作临时副本，包含无变化全流程、真实日程更新、重复确认、旧草稿阻断、原文件改动阻断、事务失败回滚、核验失败保留旧导出、输入重排和错误原件留存。

旧“核验数据库/分层/议题量化”脚本记录的是2026-11-17原始版本的验收条件，部分检查明确要求原表数据不变。后续确认了真实日程更新时，这些历史基线检查可能提示差异；当前更新应以本维护流程的原文回读、审计与核验结果为依据，不能删除历史基线来让旧检查强行通过。
