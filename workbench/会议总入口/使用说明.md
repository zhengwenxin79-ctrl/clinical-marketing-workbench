# 本地会议总入口

用浏览器打开[会议总入口](index.html)。顶部可切换“全部会议”和“领域热点”。当前领域为糖尿病，“全部会议”入口按学术覆盖范围分三层：

| 会议层级 | 当前会议系列与届次 | 跳转目标 |
| --- | --- | --- |
| 国际核心会议 | ADA → 2026 | 原ADA会议视图、议题数量与讲题、资料覆盖 |
| 国内全国性大型会议 | CDS → 2026 | 原CDS会议视图、议题数量与讲题、资料覆盖 |
| 区域重点会议 | 暂无入库资料 | 保留可点击的分类空入口，不创建示例会议 |

可按会议名称、年份、地点搜索。会议系列和具体届次分开呈现：系列是长期目录，日期、地点、资料及进入按钮属于具体年份。原有会议页面增加“← 会议总入口”，可返回目录。

## 信息从哪里来

- 名称、系列、届次、日期、地点：只读查询 `conference_series`、`v_conference_inventory`。
- 会议层级及其依据：`v_conference_tiers`。CDS按用户已确认的业务口径，ADA依据已有程序暂定，不改变其状态。
- 报告数量、类型、归类范围：`reports`、当前分析版本及 `report_classifications`，按会议隔离统计。
- ADA程序覆盖：`conference_coverage`；CDS资料时点来自已有材料元数据。
- 领域标签及本地页面路由：`入口配置.json`，属于本次入口业务配置，不伪装成外部采集结论。

没有新增表、修改数据库、补充外部会议或启动采集。三层会议不作为加权因子；目录卡片数量各自展示，领域热点采用下述会议内占比平均口径。

## 生成与更新

在“智能营销数据中心”目录执行：

```sh
python3 脚本/生成会议总入口.py
```

Windows已安装Python时：

```bat
py -3 -X utf8 脚本\生成会议总入口.py
```

生成器使用SQLite `mode=ro` 与 `query_only`，导出前后比对数据库SHA-256。输出 `会议目录快照.json`、`领域热点数据快照.json`、单文件 `index.html` 和 `生成记录.json`。页面不是实时查询数据库，资料更新后需重新生成；如果下层会议视图的数据库指纹已落后，卡片会标明“会议视图快照需刷新”。

若更新了数据库，应先重建对应会议页，再生成总入口：

```sh
python3 脚本/生成会议视图.py
python3 脚本/生成ADA会议视图.py
python3 脚本/生成会议总入口.py
```

后续新增会议须先入库系列、届次、层级及依据，再在配置中接入实际存在的会议页面路由。区域入口不会自动生成候选会议，也不会把未分类的会议默认归为区域。

复制到其他电脑时，保留整个“智能营销数据中心”目录的相对位置；总入口到会议视图、原始材料的链接才可一起使用。

## 领域热点模块（2026-11-17新增）

点击顶部“领域热点”。综合榜、国内榜、国际榜通过独立页签切换。页面以统一议题汇集会议，左侧12个研究板块随当前榜单关注度降序排列，并显示占比；中间展示议题榜和国内／国际对比，右侧随选中议题显示已分层带头人及原始讲题。点击“查看详情”可看分会议计算、全部讲者与报告、原始来源、角色依据和资料缺口；首页不铺开这些说明。

默认2026年、大会／专题／口头报告：CDS 579条、ADA 677条已归类报告，共1,256条，58个统一议题。海报模式当前仅ADA有同类资料，1,372条已归类；全部报告类型为2,628条。海报模式下CDS不参与均值，综合榜暂不计算，可切到国际榜查看，不能把无海报资料解释成0关注。

- 单场会议关注占比＝该议题去重报告数÷本会议同类已归类报告数×100%。
- 国内关注度＝国内纳入会议的议题占比算术平均；国际关注度同理。综合关注度＝国内关注度×50%＋国际关注度×50%。各地域内部会议等权，不按体量加权，不把学术角色再次加分。
- 任一地域没有同类可用分母时，综合值留空，不将另一地域提升到100%权重。当前国内国际各1场，所以50/50与前版两会等权结果相同；后续两侧会议数量不同仍保持各50%。
- 国内、国际榜分别显示本侧的报告数量和讲者，对比柱仍显示同年两侧背景。研究板块和搜索不改变分母。
- 研究板块先汇集板块内去重报告，计算每场会议的板块占比，再按相同地域/综合口径计算。板块按当前榜单关注度降序；不以议题数或议题排名平均作热度，搜索及点击板块不改变板块排序依据。较宽板块仍受范围影响。
- 每条报告在当前版本只进入一个主议题；ADA同摘要的重复展示已在入库时合并。跨会议讨论分别保留，不视为独立研究。
- 每个榜默认按本榜关注度降序，也可按报告数量或覆盖会议数排序。数值相同并列，分页每页10条。百分比保留两位小数，排序使用未取整值。
- 原始分类采用现有CDS 58议题及ADA显式模板对应，不新增题名分类、不推断研究结果。较宽议题和归类待复核状态在详情保留。
- 当前国内、国际各1场；这一统计反映已纳入会议的议程关注，不表示领域总体热度、升降趋势、研究成熟度或临床可用性。关注度排序也会受会议纳入范围和归类覆盖影响。
- 已有角色均依原资料暂定，范围和历任／候任等状态保留；无角色依据的讲者在报告详情展示，不升级成带头人。

会议正式纳入须明确届次、学术覆盖分类与资料版本，取得完整或可界定范围的官方日程，统一报告类型并完成去重和议题映射，列明未解析/另列/待归类内容，复核遗漏是否集中在特定主题。只有选摘或覆盖无法界定的资料仅补充展示，不参与主榜。当前两会按已有资料“试算纳入”，归类及跨会可比性待最终人工校准，不伪装成已经满足全部正式条件。

分类覆盖率＝同类已归类报告数÷同类已入库报告数，不是官网资料采集完整率。默认口头范围：CDS579/606＝95.54%，27条另列；ADA677/775＝87.35%，98条待归类。完整率和缺失分布未核清时，百分比与50/50不能消除偏差；应保持固定会议组合及报告范围后再比较时间变化。

新增会议时先完成入库及当前主议题归类，在 `conference_topic_scope.template_topic_id` 等映射中对齐统一议题，并在入口配置接入其会议页面；还需在 `入口配置.json` 的 `hotspot_admission` 明确设为 `main`（正式纳入）或 `trial`（试算纳入）。未评估或 `supplement` 的会议不进入计算；不以未经验证的覆盖率阈值自动判合格。重新生成即可更新榜单。尚未建立新会议分析版本时需补齐投影适配，不自动猜测对应关系。当前只读投影代码为 `脚本/领域热点数据.py`。
