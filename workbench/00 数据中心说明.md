## 先怎样查看

先用浏览器打开 `会议总入口/index.html`，按会议层级进入ADA或CDS；既有会议页面与直接打开路径继续保留。数据库不是Markdown；Obsidian里可查看字段说明、使用说明和核验报告。可以用支持SQLite的工具查看，也可在数据中心目录运行只读脚本：

```sh
python3 脚本/查看数据库.py --view v_conference_inventory
python3 脚本/查看数据库.py --view v_cds_quantity_topic_counts --limit 58
python3 脚本/查看数据库.py --view v_cds_quantity_speaker_talks --limit 20
```

## 重跑与核验

```sh
python3 脚本/导入CDS.py
python3 脚本/核验ADA资料.py
python3 脚本/核验CDS议题量化.py
```

以上为历史首轮导入器：相同资料会跳过；快照改变会停止。日常更新改用维护台，先比较再确认，不直接重复初始化。

Windows使用已安装Python时可执行（整个数据中心需一起复制）：

```bat
py -3 -X utf8 脚本\查看数据库.py --view v_conference_inventory
py -3 -X utf8 脚本\核验ADA资料.py
```
