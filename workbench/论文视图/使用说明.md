## 页面模块

- **议题研究进展**：12板块导航、51个具体议题数量榜，以及随议题切换的研究发现、证据类型和团队线索。数量与进展意义分开，不使用综合加权分，不判断升温。
- **文章池**：按来源、文献类型、板块、团队线索及时间筛选；可检索作者、题名和期刊，下载全量CSV。
- **团队与带头人**：展示首轮定向核查的3位人物，角色、文章参与和团队归属分别记录，不是完整头部团队名单。
- **信息源与规则**：检索式、来源实际状态、阅读深度、日期、去重及分类口径。

## 日期和文献类型

电子发表日优先；有已核出版社首发日期时覆盖索引刊期；缺失电子日期时按刊期暂列，明确标为“在线首发待核”。仅知月份且与窗口交叉的记录不作窗口内确定计数。例如ZNRF3论文在十月卷期出现，但出版社标注2026-08-14在线发表，本轮将其排除在8月17日起的近期窗口外，背景记录仍保留。

PubMed的Journal Article不等于原创研究。临床试验等索引研究类型、摘要方法/结果结构和7篇重点摘要复核分别留依据；大部分原创候选仍待人工校准。综述、指南、评论、病例、更正/撤稿分开。题名分类使用明示关键词，遇到多个方向保留初分依据；只出现“2型糖尿病”不会自动归到胰岛功能。缺乏明确板块时留待归类。

## 团队分层

角色轴沿用国际、全国、区域/专科、待定；“中国院士/境外科学院或医学科学院成员”另作标签，不互相替代。

需同时具备两类证据：

1. **论文参与**：原始作者全名、明确关联单位，必要时ORCID或官方文章报道辅助核对；不能只按同名匹配。
2. **人物角色**：科学院、学会、医院、大学官方履历，附角色领域与任期，不将历史网页上的现任描述直接当作当前任期。

当前纪立农与Daniel J. Drucker有姓名/单位与官方角色依据；宁光的院士身份有官方依据，论文跨语言身份关联仍明确留待核。对每篇论文只标第一作者或共同作者参与；未拿到通讯作者、研究总PI或官方牵头说明时，团队归属保留待核，不能称为其团队主持。教授、末位作者、知名机构和文章影响因子均不自动构成“大PI”认定。

当前3位仅是定向验证样本，不代表其他作者不具备同等学术角色；角色不参与论文数量加分。联系和合作机会本轮不评级。

## 数据表与关系

首轮在SQLite新增11张表、2个查询视图；本次议题解释层再追加4表1视图，当前55表21视图、版本7，原51表内容保持。议题新增表见本轮改造说明，没有新增Biomarker数据。

| 表 | 主要字段与用途 |
| --- | --- |
| `literature_runs` | 采集窗口、检索清单、文件指纹与范围 |
| `literature_sources` | 六本核心来源及主题补漏入口、实际覆盖状态 |
| `literature_source_checks` | 每轮检索式、返回数、读取状态、缺口与原始文件 |
| `literature_papers` | DOI/PMID、题名、期刊、日期及口径、类型、摘要、阅读层级与来源 |
| `literature_authors` | 论文ID＋作者序、原始姓名、关联单位、ORCID、通讯身份状态 |
| `literature_classifications` | 论文到现有研究板块的主归类、相关范围、依据与复核状态 |
| `literature_people` | 已核或待核人物身份、研究领域 |
| `literature_person_roles` | 人物角色层级、院士标签、官方来源、任期与核查日期 |
| `literature_author_links` | 作者记录到人物的核对关系；论文署名角色和负责人状态 |
| `literature_highlights` | 7篇具体研究问题、摘要提炼、选读理由和待核事项 |
| `literature_discovery_candidates` | 广检索PMID发现池；区分已读元数据与仅有编号 |

关联：来源→每轮检查；论文→作者；论文→主板块；作者→已核人物→官方角色；论文→重点进展。`v_literature_pool`提供页面主池判断，`v_literature_board_counts`按论文ID计数。论文不是独立研究实体，不能据篇数推断独立验证数量。

## 留档、生成与后续

原始检索JSON、PubMed XML、中文目录及团队身份读取记录在 `原始资料/论文首轮_2026-11-17/`。规则SQL在 `规则与说明/006_论文热点.sql`。备份位置见原始资料内的 `本轮备份位置.txt`。

离线重建（不会联网）：

```sh
python3 脚本/准备论文首轮.py
python3 脚本/导入论文首轮.py
python3 脚本/应用论文议题复核.py
python3 脚本/生成论文视图.py
```

`采集论文首轮.py`为本次时间窗口的采集器，已有文件会使用缓存，不是已经配置的每周生产任务；重新联网更新需明确变更窗口和留档目录。中文目录补查使用网络检索读取记录留档，不宣称已实现完整自动解析。

下一轮优先补齐中文期次和独立文章摘要、校准原创候选及板块归类、核对重点论文通讯作者和牵头团队。连续同口径数据积累后再设计趋势比较。

检索和日期口径参考：[PubMed官方帮助](https://pubmed.ncbi.nlm.nih.gov/help/)。

## 2026-11-18 文献类型简化

文章池主分类改为综述、研究类、会议类，另保留其他／待确认；具体研究设计、复核状态和PubMed原始类型放在详情。综述包含系统评价和Meta分析；会议类限有明确会议报告、摘要或大会讲座依据的文章，已发表完整研究论文仍按研究类分类。指南、共识、评论、更正及类型不明者保留具体类型，不硬归入三类。

已有618条记录的展示分类为综述71、研究类310、会议类3、其他／待确认234；这是跨时间、跨来源全量记录的类型分布，不等于议题榜。主数量榜仍为核心四刊窗口内160篇、51议题。展示字段来自只读导出，不修改数据库，旧type=original链接兼容研究类筛选。未新增采集、未发布。分类逐条依据见文献分类快照.json；核验见文献分类核验.json。
