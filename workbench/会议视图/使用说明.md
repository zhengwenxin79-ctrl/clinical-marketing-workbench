# CDS本地会议视图

用浏览器打开[会议视图首页](index.html)。此页面与既有研究台独立，数据来自 `数据库/marketing.db` 的只读查询，使用已有2026-11-16资料快照。

## 怎么看

| 入口 | 展示 | 点击后查看 |
| --- | --- | --- |
| CDS会议总览 | 会议日期地点、606条学术报告、12个研究板块的数量分布 | 板块所属议题、会议官网、已保存日程 |
| 议题数量与讲题 | 58个复核工作议题的报告数与占比；支持按板块和关键词筛选 | 具体讲题、讲者、分类依据及角色来源 |
| 讲者信息 | 533条讲者来源身份；按国际/全国/区域／专科/待定筛选，搜索姓名、角色领域、单位与讲题 | 本届报告、已有简介、学术角色及原始来源 |
| 全部报告 | 606条报告；可按日期、报告类型、统计范围筛选，或搜索讲题和人物 | 原题、时间、会场、专题、讲者、来源定位和原始结构化记录 |
| 来源与统计口径 | 数据覆盖、计数口径、缺口和436份随包文件目录 | 来源元数据、本地快照、原始网址及文件指纹 |

推荐路径：**总览 → 研究板块 → 具体议题 → 报告详情 → 讲者 / 原始来源**。也可从顶部搜索直接定位报告、讲者或单位。

## 数量怎样理解

- 完整日程有797条项目、148个专题。大会报告11条、专题报告259条、论文发言336条，共606条学术报告；其余191条日程项目不计入学术报告列表。
- 606条中，579条归入58个复核工作议题；16条培训、5条科研方法与投稿、6条综合题目另列。原44议题全部复核，9个组合议题拆分，13条报告调整主归属；新版仍是AI题名复核，待人工校准。
- **一条报告只进入一个主议题。** 按报告ID去重；交叉标签不重复加次数。各议题及板块占比以579条为分母，筛选后不改变分母。
- 柱状图只展示本届报告数量，不计算综合热度分。讲者角色不叠加计分；这版用于看清议程与来源，为后续热点判断提供底表。
- 533条为“姓名＋来源单位”区分的讲者身份记录，同名/跨单位身份尚未全部核清；原有126条身份的角色提取保留；新分层依据简介逐项复核，国际6、全国96、区域／专科43、待定388。145条已分层身份共150条原文依据，均为暂定，注明角色领域及历任/候任等状态；任期未独立核查。
- 目前是会前日程数据，尚未导入报告结果。不能把报告数直接当作独立研究数或临床成熟度。

## 数据怎样连接

```text
数据库/marketing.db（只读）
    ↓ 脚本/生成会议视图.py
会议视图/会议数据快照.json
    ↓ 嵌入HTML（同时嵌入CSS和JavaScript）
会议视图/index.html
    ↓ 相对路径
原始资料/CDS2026/…（本地来源）
```

页面不实时访问SQLite，也不需要联网加载数据或安装前端依赖。报告的来源栏同时保留官方日程链接、已保存的完整日程和结构化记录定位；点击外部网址时需联网。全文资料和来源文件中的其他网页内容保持原样。

只复制 `index.html` 可以查看内嵌信息；若需要继续打开本地原始来源，请复制整个“智能营销数据中心”目录，保持相对目录不变。

## 如何重新生成

在“智能营销数据中心”目录运行：

```sh
python3 脚本/生成会议视图.py
```

Windows已安装Python时：

```bat
py -3 -X utf8 脚本\生成会议视图.py
```

当前生成器针对这次CDS首轮导入，校验606条报告、58个议题、12个板块与579条归类报告。数据规模或范围改变后，应同步调整生成器的范围与验收基线，再重新核验；不要通过修改输出HTML来维护数据。

导出使用SQLite `mode=ro` 和 `query_only`；导出前后比对数据库SHA-256。`生成记录.json` 保存数据库、快照、网页指纹。更新数据库后，浏览器中已打开的HTML不会自动变化，需要重新生成并刷新。
