# 吉因加临床科研营销知识包

> **用途：为会议热点、前沿文献和PI匹配提供“公司能力与证据底座”。**
>
> 使用顺序：先看业务与能力，找到相关条目，再查证据台账；需要具体参数时回到来源。糖尿病是当前小方案的试点方向，大方案保持原样。

## 一、这份知识包整理了什么

本版根据用户提供的v1和v2 OCR增补重组。**v1保留业务与资料结构，v2补充读取结果；主包整合可使用的信息，台账保留差异和缺口。** 不是把v2的全部表述自动认定为修正后的事实。

按原知识包自述：已定位三个库的目录节点，下载13份原件；OCR语料覆盖其中11份、354页，识别172页。原始材料版本主要为2023—2025年。这些覆盖量和OCR结果本轮未重新执行验证，不能据此宣称全文覆盖整个公司知识库。

本轮完成的是文档整理与交叉检查：未重新下载钉钉原件、核图或复核论文，也未更新实时注册、报价和服务状态。源文件中的行动建议保留为历史建议，不作为已经执行的任务。

## 二、业务定位与领域范围

### 当前业务主线

按2026-11-10与Mentor的讨论，临床科研业务当前重点是：**从尚未解决的临床问题出发，匹配组学和分析方法，支持有临床转化前景的Biomarker发现研究。** 靶点发现与验证是延伸方向。

公司拥有的技术与产品用于判断潜在切入点；是否适配某个病种、样本和用途，需要分别补证据。肿瘤、感染与药企资料可作交叉能力参考，但不替代本业务线的当前重点。

### 六个工作分组的资料入口

以下沿用v1的工作分组，方便找材料；不作为已确认的正式组织架构或排他性疾病分类。

| 工作分组 | 本批知识包中的资料线索 | 当前使用方式 |
| --- | --- | --- |
| 风湿免疫 | 单细胞免疫组库；SLE等文献目录线索 | 先定位病种方案；“无专属方案”仅限本批读取范围 |
| 内分泌代谢 | 单细胞、GM-seq、菌群研究线索；糖尿病／肥胖文献目录 | 糖尿病试点入口；尚缺可直接确认的糖尿病能力适配证据 |
| 神经精神 | 脑神经案例图册；脑脊液及单细胞／空间材料入口 | 用于理解研究设计，逐项区分外部论文和公司合作成果 |
| 心血管 | 风险分层与分子分型材料；新靶点方案已定位线索 | 提取问题与研究路径，数值和公司承接能力另核 |
| 呼吸慢病 | 呼吸单细胞与时空组学材料 | 用于方法和样本适配研究；COPD／ILD具体应用证据待补 |
| 泛血管及器官损伤 | cfDNA甲基化溯源、SI-AKI、移植肾材料 | 保留不同疾病场景，分别核实，不合并为通用肾损伤性能 |

**本次修正**：v1中的“科研体系六大方向”一栏混列了多项应用主题，不作为当前六大领域的依据。糖尿病与肾病、心血管等交叉主题可多重标记，不重复计算为不同研究。

## 三、公司能力清单：先知道可以查什么

表中C编号沿用原知识包，便于回查；不是现有[[wenxin/实习实践/吉因加临床科研能力表|36项能力表]]的编号，也不表示独立SKU数量。

“包内有记载”只表示本轮在用户提供的整理文档中读到；**原件载明、疾病验证、当前可交付、注册状态是不同结论**。不将单一“A/B/C/D”分类同时作为技术形态、服务状态和资质证明。

| 原编号／条目 | 包内描述的研究作用 | 包内描述的输出／交付线索 | 本轮确认范围与关键缺口 |

| **补读：cfRNA** | 既有项目中有液体活检与动态研究资料线索 | 本批知识包未提供完整能力卡 | 记为“本批未取得专门资料”；回到原方案地图定位，不从公司技术清单删除 |
| **补读：虚拟细胞／药物扰动** | 既有项目中有平台与方案线索 | 本批知识包未提供完整能力卡 | 分开核计算预测、药物扰动与基因扰动；补当前服务范围，不由资料缺失认定不存在 |

**参数与原始索引不重复堆在主包中**：由台账定位到v1、v2的具体条目，再回原件。保留旧数值用于核对，不把它们作为当前送样、报价或性能承诺。

## 四、研究案例与营销判断怎样使用

### 两张已有疾病卡的正确位置

- **SI-AKI及器官损伤卡**（v1 §6卡片1）：保留为“如何把问题、技术、文献、团队线索和沟通问题连起来”的示例。卡片混入了移植场景资料，疾病与对照人群须重新拆分，不能直接当糖尿病肾病的验证卡。
- **心血管分型卡**（v1 §6卡片2）：保留为多路径证据整理示例。队列数字和对应关系需核；其中的技术关联是候选假设，不是已经确认的产品方案。

研究证据之后宜按“具体问题—人群与样本—方法与对照—结果与局限—公司参与身份—能够支持的主张”组织。**公司参与身份**分为公司合作／交付、外部原始研究、第三方平台案例、身份未核实。

### 宣传、PI画像与合作建议

v1中的建议讲题、PI画像和合作阶梯继续保留在来源中，归为**研究／营销建议**。固定人数门槛、统一预实验样本量、“比某指标早若干月”“竞品少／最独特”等结论，不进入已确认事实。

宣传选题需说明文章实际支持什么；客户匹配需说明研究条件与未知项；是否有需求和合作意愿由沟通确认。测出相关信号、形成机制假设、完成功能验证和支持临床用途，分别记录。

## 五、怎样支持当前营销智能体

| 模块 | 从知识包调用什么 | 应形成什么判断 |
| --- | --- | --- |
| 热点洞察 | 能力清单、研究方法、证据边界和待核项 | 新成果与公司有什么具体关联，值得深入还是仅作观察 |
| 会议与PI机会 | 研究所需样本／数据、案例设计、沟通问题 | 哪类团队值得了解，会议中应关注哪些报告和人员 |
| 后续反馈 | 匹配时的假设与缺口 | 实际沟通确认或推翻了什么，能力理解与画像如何修正 |

糖尿病试点先使用本包作为**能力查询入口**。待讨论确定问题分类后，再将会议成果、文献与团队接进来；不因为其他领域素材更全就更换试点，也不直接将其他疾病方案改名为糖尿病方案。

下一批资料优先补三类：糖尿病相关现行方案与文献；cfRNA、甲基化及实际会用到技术的交付依据；能回查的代表论文与报告样例。全量竞品、全部注册资产与全行业公司材料按实际匹配需求再扩展。
