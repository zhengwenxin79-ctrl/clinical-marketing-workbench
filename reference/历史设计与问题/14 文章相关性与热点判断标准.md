# 文章相关性与热点判断标准

> **逐篇判断“与我们有什么关系”，逐主题判断“为什么值得持续关注”，再决定下一步研究与业务动作。**

本文件将本次讨论及原执行任务书中的判断口径整理为后续采集、筛选与复核的试行标准。适用于期刊文章、会议摘要和报告线索，连接“产品与技术动态”“会议热点洞察”两个入口。具体操作规则为项目工作约定，可用真实案例与mentor校准；不作为行业通用评价量表。

本次仅保存标准，未启动新采集、批量重评既有研究或在网页上线自动评分。营销大方案与既有研究记录继续保留。

## 1. 三项判断分别记录

| 判断 | 基本单位 | 回答什么 | 输出 |
| --- | --- | --- | --- |
| 文章相关性 | 一项研究 | 领域、问题、技术与我们有什么关系？ | 直接技术关联／相关方法参考／关联待判断／领域背景 |
| 热点判断 | 一个具体研究主题 | 有哪些独立进展，新增了什么，为什么值得持续关注？ | 主题状态、四维依据、代表证据与缺口 |
| 公司承接适配 | 具体研究环节 | 公司能以什么样本、平台和流程参与？ | 已确认适配范围／部分适配／待核实及核实依据 |

技术相关的单篇论文可以进入技术动态；领域重要但技术关联较弱的进展进入其它热点。公司适配状态单列，不影响保存有价值的研究线索。当前业务优先关注有临床转化前景的Biomarker筛选，患者分型、早期风险、应答、监测和预后问题优先细读；机制研究按能否连接具体问题确定投入。

## 2. 采集范围与材料准入

### 2.1 每轮先固定范围

- 记录截止日、来源名单、检索式、日期字段、过滤条件、实际读取范围及失败入口。
- 沿用原任务书的起步口径：文章默认回溯12个月，会议盘点当年实际届次。更早关键研究标为背景；跨年会议或其它补充窗口说明原因。
- 产品技术路径围绕“技术＋糖尿病应用”补检；会议路径先读可得议程、摘要目录，再追具体研究。领域基础检索也要保留，便于发现尚未关联公司技术的重要问题。
- 区分研究发表日、会议摘要刊出日、现场报告日与本项目收录日；日期未知就保留待核。

### 2.2 先判断材料能支持什么

| 材料 | 使用方式 |
| --- | --- |
| 原始研究论文 | 提取问题、设计、结果与验证；标明读到摘要还是全文 |
| 原始会议摘要／报告 | 按实际读到的结果保存，注明会议、摘要号及读取层次 |
| 预印本 | 保存版本与日期，单列发表状态，后续关联正式论文 |
| 未来会议议题／仅有标题的条目 | 进入待关注线索，提出追踪问题；结果另行补核 |
| 综述、指南、共识 | 用于组织主题、理解临床基线和追原始证据 |
| 官方报道、媒体、企业发布 | 用于定位研究或产品更新；研究结论追溯原始资料，产品能力按对应证据核实 |

题目和摘要能显示相关问题时，即可进入候选池；原始资料不足进入“待补原文”，不因访问失败判为无关。确认超出范围、没有明确问题连接时，记录“不纳入本轮”及理由。阴性、无增益和相互矛盾的研究同样纳入判断。

## 3. 文章相关性：逐篇检查五个维度

| 维度 | 必须回答的问题 | 最少留下的依据 |
| --- | --- | --- |
| 领域相关 | 涉及哪类糖尿病、人群、疾病阶段或并发症？邻域研究怎样连接糖尿病问题？ | 人群、病种、场景；直接领域／邻域／范围外 |
| 问题相关 | 想解决什么诊断、分型、风险、应答、监测、预后或机制问题？ | 一句话具体问题及其业务关注理由 |
| 技术相关 | 实际测了什么、从哪里测、用什么方法？ | 样本→组分→检测对象→平台→分析方法；未知项待核 |
| 流程适配 | 与公司现有能力接近到哪一步？ | 能力底表编号、确认日期、匹配点和待核环节 |
| 研究用途 | 可以据此设计什么研究或选择什么验证环节？ | 明确对象、研究问题、技术及评价终点的一句话 |

领域、问题决定是否值得保留；技术决定归属；流程适配决定承接状态；研究用途说明下一步价值。五个维度分别说明，不凑一个相关性总分。

### 3.1 四种相关性归属

| 归属 | 判定条件 | 页面与后续动作 |
| --- | --- | --- |
| **直接技术关联** | 原文明确实际使用所关注的技术类别，并连接具体糖尿病问题 | 进入对应技术动态；提取研究用途，进一步核对公司流程 |
| **相关方法参考** | 问题或检测对象有关，样本、组分、平台或方法存在明显差异 | 保留方法参考；写明可借鉴的研究设计和需验证的转换环节 |
| **关联待判断** | 问题值得关注，技术细节或公司匹配环节尚未明确 | 列出具体补核问题，补资料后重新归属 |
| **领域背景** | 有助于理解治疗、监测、管理或临床需求，当前主要价值在问题与场景 | 进入其它热点或会议研究；说明可提出的后续问题 |

以上为逐项技术关联的判断；同一研究允许关联多项技术。与现有数据衔接时，`product_relation.group`的product表示已有直接或相关技术链接，具体看links中的direct／related；pending和other分别对应关联待判断、领域背景。此说明不要求本轮改写数据结构。

### 3.2 公司承接适配单独确认

- **已确认适配范围**：有现行能力材料或产品／技术复核，明确样本、检测对象、平台及交付环节，记录证据与日期。
- **部分适配**：部分环节已有依据；逐项说明可参与的环节及需补充的条件。
- **待核实**：尚缺当前流程或交付依据，列出需要向产品／技术确认的问题。

外部研究的方法与性能按原文保存；吉因加的能力依据从公司资料及复核取得。历史材料保留日期和原有确认范围。

### 3.3 分类与表达实例

| 既有记录 | 技术／问题归属 | 可写的研究用途 |
| --- | --- | --- |
| R16：孕期血浆cfRNA | cfRNA直接技术关联 | 筛选诊断前GDM风险标志物，评价其对临床模型的增量价值并设计独立验证 |

## 4. 热点判断：归并主题后检查四个维度

主题应具体到可比较的问题，例如“血浆cfRNA用于GDM早期风险识别”“EV蛋白与T1D部分缓解”。“单细胞”“糖尿病”可作导航标签，聚合判断时继续细化问题、人群或应用场景。

| 维度 | 怎么检查 | 判断记录必须提供什么 |
| --- | --- | --- |
| **关注信号** | 是否有独立研究、不同团队或连续会议与文章关注同一问题？ | 研究ID、团队、时间与来源；区分议题关注、结果与重复传播 |
| **新增价值** | 相比已有基线，增加了新机制、新人群、新方法、外部验证或改变判断的阴性证据吗？ | 原有认识／参照研究＋本次具体增量 |
| **临床科研意义** | 推进了什么重要问题？产生了哪些可操作的后续研究？ | 对诊断、分型、应答、监测、预后的意义及下一步问题 |
| **证据成熟度** | 处于机制探索、候选发现、内部验证、独立验证或临床研究哪一步？ | 原文读取层次、研究设计、验证方式、相互支持或冲突及待核项 |

逐维写结论和依据，证据不足标“待补”。采用文字分级，不预设热点数量，不将关注度与证据成熟度加权成一个总分。期刊影响力、会议级别与重点报告位置用于安排阅读优先级；文章内容、独立证据和实际增量用于最终判断。引用量、媒体报道与企业宣传可作发现线索，记录时注明其性质。

### 4.1 主题状态与证据要求

以下为项目试行判定口径，执行者逐项列证据，复核者据证据确认；遇到边界案例保留理由，供mentor校准。

| 状态 | 判定口径 | 仍需什么 |
| --- | --- | --- |
| **候选线索** | 出现具体且有价值的研究或会议议题，独立证据、结果或来源覆盖仍有限 | 补原始结果、独立团队及相关研究 |
| **新兴方向** | 已核出相对既有基线的新问题或新方法，并有独立研究跟进；同队列追加分析需说明 | 列出独立研究及各自增量，继续观察复现与发展 |
| **持续热点** | 在多个独立研究、团队及连续时间节点中持续出现，能说明问题如何推进 | 明确时间跨度、独立性和实际覆盖范围 |
| **重要进展** | 某项研究对已有认识、验证路径或实践问题产生明确增量，且现有证据支持该表述 | 给出参照、关键结果与复核依据；可与上述状态并存 |

“重要突破”需进一步复核改变了什么及证据能支持到哪一步。单项重要研究可标重要进展；一项技术即使很贴近产品，也先按具体主题及已有证据确定状态。

### 4.2 “升温”需要可比的时间数据

若要使用升温、降温或排名，先固定来源、主题定义、检索与纳入规则、日期口径和去重方法，并使用长度相同、覆盖可比的连续时间窗。可以试行比较相邻90天，但需记录会议周期、出版滞后及资料缺失；覆盖变化时先说明影响。

当前同日B01—B03采集的范围不同，只能说明新增覆盖。此前未覆盖的主题标“本轮新收录”，历史基线不足标“趋势待判断”。

## 5. 原始证据、独立性与复核要求

1. **追到具体依据**：关键事实留下原始链接、DOI／注册号／摘要号、读取层次及可定位的结果。拟作为主题代表证据时，优先补读原始结果与局限。
2. **关联研究版本**：同一研究的会议摘要、预印本与正式论文连接为版本；转载和报道连接原研究。共享队列、主研究／亚组分别标注。
3. **分开计数**：记录条目数、去重研究数、独立队列／验证及团队情况分别说明。多中心合作的一篇论文仍按一项研究处理。
4. **按研究问题评价质量**：机制研究看模型、对照、重复与功能支持；标志物研究看人群和采样时序、混杂、验证、预测增益及临床参照；临床干预看对照、主要终点、失访与不良事件。分析方法应与结论匹配。
5. **保留反向证据**：阴性、无增益与冲突结果写入主题判断；更新主题状态时说明它们改变了什么。
6. **记录复核**：执行者给出初判，代表证据与主题升级安排人工复核；尚未复核则明确记录状态。不要填写未发生的复核人或复核日期。

## 6. 采集、筛选与输出顺序

1. 固定本轮范围，从来源目录选择实际检查的入口，保存检索／读取记录。
2. 按标题、摘要或议题初筛：纳入候选／领域背景／待补资料／不纳入本轮，逐项留理由。
3. 提取研究事实，完成五维相关性判断、技术归属及公司适配状态。
4. 关联版本和共享队列，将研究归并到具体问题主题。
5. 用四个热点维度形成主题判断，保存独立证据、状态、缺口与下一步。
6. 决定后续动作：补原文、继续跟踪、技术复核、深入团队调研或准备交流选题。面向销售的材料明确研究问题和可讨论环节。
7. 保存研究台账、主题卡及来源覆盖记录，复核后再更新相应页面内容。

优先级按任务目的确定，以下为排期参考：

| 情况 | 推荐动作 |
| --- | --- |
| 技术关联明确＋研究增量清楚 | 优先核读代表证据、确认适配、深入团队问题 |
| 技术关联明确＋证据或关注信号有限 | 进入技术观察池，补结果与独立验证 |
| 领域进展重要＋当前技术关联较弱 | 保留会议／领域热点，寻找需求变化和后续研究场景 |
| 问题模糊＋资料不足 | 保留定位信息与待补问题，降低当前投入 |

## 7. 可复制的判断记录模板

### 7.1 研究级记录

```markdown
### [研究ID] 研究标题
- 来源与原始链接：
- DOI／注册号／摘要号；发表与会议日期：
- 材料类型与实际读取层次：
- 临床科研问题、人群与场景：
- 样本→组分→检测对象→平台→分析方法：
- 主要发现与关键指标：
- 设计、验证与局限：
- 领域相关：直接领域／邻域／范围外；依据：
- 问题相关：具体问题与当前业务意义：
- 技术相关：直接技术关联／相关方法参考／关联待判断／领域背景；依据：
- 流程适配：已确认范围／部分适配／待核实；能力编号、证据与日期：
- 研究用途或后续问题：
- 关联主题、同研究版本与共享队列：
- 初筛决定与理由；下一项补核：
- 判断人／工具、日期、规则版本与复核状态：
```

### 7.2 主题级判断

```markdown
### [主题ID] 具体问题主题
- 本轮范围、时间窗口与实际覆盖：
- 关注信号：独立研究／团队／时间节点及对应ID：
- 新增价值：参照是什么，本次增加什么：
- 临床科研意义与下一步问题：
- 证据成熟度、反向证据与缺口：
- 版本、共享队列与独立性说明：
- 主题状态：候选线索／新兴方向／持续热点；理由：
- 是否有重要进展：具体研究、增量及依据：
- 趋势：待判断／有可比数据的判断；数据口径：
- 公司可参与环节与适配状态：
- 下一步动作、判断日期、规则版本与复核状态：
```

两个模板用于下一轮新增或复核记录；既有记录可逐条补齐，尚未填写的字段保持未知。
