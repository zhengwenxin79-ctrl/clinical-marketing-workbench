# 糖尿病科研热点工作台：设计与评级标准

## 1. 建设目标

以糖尿病为试点，搭建营销智能体的**热点洞察模块**：持续发现研究进展，判断与公司技术的关系，提炼可开展的临床科研问题，为后续PI调研和销售交流提供依据。

优先关注有临床转化前景的Biomarker筛选，以及患者分型、早期风险识别、治疗应答、监测与预后问题。试点跑通后，再向其他领域复用。

## 2. 页面如何组织

| 主模块 | 发现路径 | 页面内容 |
| --- | --- | --- |
| **产品与技术动态** | 从技术找应用 | 按cfRNA、甲基化、单细胞等7类技术查看糖尿病研究；展开相关信息源 |
| **会议热点洞察** | 从会议找问题 | 展开CDS、ADA、EASD等会议来源，按9类自建研究主题查看议题与进展 |

两条路径共用研究记录，每条展示：**谁在研究 → 解决什么问题 → 使用什么方法 → 得到什么发现 → 可以继续做什么**。设计、指标、局限及原始来源在详情中查看。

整体流程：**来源 → 研究记录 → 相关性判断 → 主题归并与热点判断 → 公司适配与团队线索 → 后续交流。**

每场优先获取**官方议程→原始摘要／报告→对应论文**，提取研究问题、方法、结果与团队。计划议题用于发现方向，已报告结果用于分析进展，后续按下文相关性与热点标准判断。

## 3. 评级标准一：文章与我们是否相关

逐篇检查五项：**领域、人群与问题是否相关；实际使用什么技术；流程能否适配；可以开展什么研究。**

| 归属 | 判断依据 | 后续处理 |
| --- | --- | --- |
| **直接技术关联** | 原文实际使用关注的技术，解决具体糖尿病问题 | 纳入技术动态，提炼用途并核对承接流程 |
| **相关方法参考** | 问题或检测对象相关，样本、组分或方法存在差异 | 提取可借鉴的设计和需要验证的转换环节 |
| **关联待判断** | 问题有价值，技术或匹配环节尚不明确 | 列出补核问题，再确定归属 |
| **领域背景** | 主要提供治疗、监测或管理需求信息 | 保留领域价值，寻找后续科研问题 |

这四类用于归属与排期。公司承接能力另标**已确认适配范围／部分适配／待核实**，依据现行材料及产品、技术复核确认。

## 4. 评级标准二：是否形成研究热点

以**具体研究主题**为单位，分别记录四项依据：

- **关注信号**：是否有独立研究、不同团队及连续时间节点的关注？
- **新增价值**：相比已有认识，增加了什么机制、方法、验证或重要阴性证据？
- **临床科研意义**：推进了什么问题，带来哪些可开展的后续研究？
- **证据成熟度**：处于探索、候选发现、内部验证、独立验证或临床研究哪一步？

| 主题状态 | 判定依据 |
| --- | --- |
| **候选线索** | 有具体且值得关注的研究或议题，独立证据或结果仍待补充 |
| **新兴方向** | 出现有增量的新问题或方法，并有独立研究跟进 |
| **持续热点** | 多个独立研究、团队在连续时间节点持续推进同一问题 |
| **重要进展（附加标记）** | 某项研究对已有认识、验证路径或实践问题带来明确增量，可与上述状态并存 |

每次评级附研究ID、来源、日期及判断理由。会议与论文同研究关联去重，共享队列注明关系；阴性结果纳入判断。期刊与会议级别用于安排阅读顺序，最终依据具体研究。升温、降温需建立覆盖可比的时间数据后再评价。
