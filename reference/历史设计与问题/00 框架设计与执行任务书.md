## 一、整体结构

**来源池 → 研究进展记录 → 问题分类与主题归并 → 热点判断 → 知识地图**

| 层次 | 回答的问题 | 产出 |
| --- | --- | --- |
| 领域热点 | 近期大家在研究什么，有哪些重要新进展？ | 热点主题及关注依据 |
| 临床科研问题 | 每个主题想解决什么，还缺什么？ | 具体问题与证据关系 |
| 团队线索 | 哪些团队正在推进这些研究？ | 作者／讲者及其研究关联 |
| 后续营销判断 | 公司可能参与哪一环，值得进一步了解谁？ | 下一阶段的能力匹配与机会分析 |

本轮重点是前三层。公司技术清单提供后续查询依据，不提前限定哪些热点可以被发现。糖尿病包含不同类型、人群、疾病阶段和并发症，不能用已有糖尿病—肾脏资料代表全领域。

## 二、来源池：核心覆盖，专题补充

以下是候选来源设计，尚未核对具体年度安排、官网入口与可获取材料。执行时先核验当届信息；不存在当年会议或无法获取资料时，如实记录。

### 会议

| 层次 | 候选来源 | 重点获取 |
| --- | --- | --- |
| 国内核心 | 中华医学会糖尿病学分会全国学术会议 | 国内主题、具体研究、临床问题和团队 |
| 国内补充 | 中华医学会内分泌学分会全国学术会议 | 与糖尿病直接相关的代谢、肥胖及内分泌研究 |
| 国际核心 | ADA Scientific Sessions；EASD Annual Meeting | 重要临床试验、机制、分型、并发症和新方法 |
| 国际补充 | IDF World Diabetes Congress，按实际届次纳入 | 全球管理、公共卫生和区域差异 |
| 技术专题 | ATTD | 监测、治疗技术及相关研究 |
| 按问题补充 | 肾脏、心血管等专科重要会议中的糖尿病研究 | 已出现主题的深入证据 |

来源优先为主办方、当届会议日程、官方摘要、报告资料与对应原始论文。媒体用于发现线索，再追原始来源。议程只证明安排了某主题；结果需要摘要、报告或论文支持。未来会议的议题单列为“待关注”，不算已报告的新成果。

### 期刊

| 用途 | 候选来源 | 重点获取 |
| --- | --- | --- |
| 糖尿病核心研究 | Diabetes Care、Diabetologia、Diabetes、The Lancet Diabetes & Endocrinology | 临床、机制、标志物及管理研究 |
| 重要临床与转化 | NEJM、The Lancet、JAMA、Nature Medicine | 重要试验、转化及治疗进展 |
| 机制与方法补充 | Cell Metabolism、Nature Metabolism、Science Translational Medicine等 | 机制、多组学、细胞及方法进展 |
| 国内临床背景 | 中华糖尿病杂志、中华内分泌代谢杂志 | 国内研究、指南共识及临床关注点 |

原始研究作为进展证据主体；综述帮助组织主题，指南共识帮助理解临床基线。评论、新闻和企业发布分别标记，不与原始研究混计。

## 三、研究记录：每条提取什么

以研究为基本单位，保留不同来源和发表版本之间的关系。

| 字段 | 最少需要记录的内容 |
| --- | --- |
| 来源 | 会议／期刊、题目、原始链接、发布日期、会议报告日期、读取层次 |
| 具体问题 | 研究究竟想解决什么，属于哪类临床或科研问题 |
| 人群与场景 | 糖尿病类型、疾病阶段、并发症／共病、国家或研究场景 |
| 设计与方法 | 研究类型、样本量、样本／数据、技术、干预和对照；缺项标未知 |
| 主要结果 | 一句话结论、关键结果、较已有认识新增了什么 |
| 证据边界 | 验证方式、局限、尚未解决的问题、原文支持范围 |
| 团队 | 作者／讲者、单位、研究角色及身份依据；不把全部作者当报告人 |
| 分类与关联 | 主问题类别、主题标签、研究ID、DOI／注册号／摘要号等已核标识、相关版本 |

会议摘要、预印本和正式论文属于同一研究时关联去重。相同队列的不同分析可分别记录，但注明共享数据，不视为完全独立的验证。

## 四、分类：问题作主干，多维标签补充

| 主分类 | 核心问题 |
| --- | --- |
| 发生机制与疾病分型 | 为什么发生，是否存在不同机制与亚群？ |
| 诊断与风险识别 | 如何识别疾病、发病或进展风险？ |
| 治疗与应答差异 | 哪些干预有效，谁获益，效果怎样维持？ |
| 并发症、共病与预后 | 哪些人进展，哪些器官受累，如何判断结局？ |
| 监测与长期管理 | 怎样追踪状态变化，支持持续管理？ |

每条研究指定一个主要问题类别，允许交叉标签。标签包括人群（1型／2型／妊娠及其他）、场景（肾脏／心血管／眼／神经等）和方法（临床数据／影像／遗传／组学／AI等）。

这是初始分类，不是固定目录。出现无法合理归类的重要研究时，先保留并说明，再调整分类；不靠强行归类丢弃新主题。

## 五、热点判断：四个维度分别说明

| 维度 | 判断依据 |
| --- | --- |
| 关注信号 | 是否在不同会议、独立团队或多项研究中反复出现？具体有哪些来源？ |
| 新增价值 | 新结果相对已有认识改变了什么？重复研究还是实质增量？ |
| 临床科研意义 | 对疾病认识、诊断、治疗、监测或后续研究有什么影响？ |
| 证据成熟度 | 处于探索、验证或临床研究的哪一步？哪些结论仍不确定？ |

可并存的主题标签为：**持续热点、新兴方向、重要突破、待核线索**。证据成熟度单列，不与关注度合成总分。

首轮定向采集只能形成“在已覆盖来源中观察到的热点线索”。缺少历年可比数据时，不宣称热度上升；缺少全量分母时，不生成占比或精确排名。负面研究和未证实结果也可改变方向判断，不仅收录积极结果。

## 七、首轮执行任务书

### 默认试跑范围

以下为便于启动的执行建议，区别于上面的完整候选来源池。

- **截至日期**：2026-11-11。后续若在其他日期运行，应先明确新的截至日期并记录。
- **会议窗口**：2026-01-01至截至日期内已举行并有可核资料的会议；当年未来会议仅列待关注。
- **文章窗口**：2025-11-11至截至日期的新发表原始研究；更早关键研究只作背景，注明用途。
- **首轮样本**：先盘点全部候选会议的当年状态；深入读取国内核心会议1场、国际核心会议1场，并检索四种糖尿病核心期刊。国际会议选择资料更可得的一场，记录选择理由。
- **补充来源**：核心材料已指向重要主题或研究时，再补相关临床、机制期刊或专科会议；不为凑来源数量泛搜。
- **目标**：验证提取、分类和判断方法，形成可审阅的主题初版。首轮不是国内外年度完整综述，不规定必须得到几个热点或某种排名。

### 执行顺序

1. **来源盘点**：核对会议身份、届次、日期、官方材料入口与可读性；记录期刊检索入口、检索式与时间窗口。
2. **建立候选研究池**：阅读核心会议完整可得议程并标记主题，再提取重点报告／摘要；核心期刊使用糖尿病相关词检索，记录过滤与排除依据。
3. **研究级核实与提取**：按第三节记录；对拟作为代表证据的研究，尽量回到原文结果与局限。未取得正文则保留摘要层级。
4. **关联去重**：匹配会议与论文版本、共享队列和研究标识；保留无法确认的关系。
5. **归并主题**：从实际研究中归纳主题，再放入初始问题分类。保留主题与支持研究的双向关系。
6. **形成热点判断**：逐主题写四维理由，列支持、限制及反向证据；提出需要补来源的主题。
7. **交付与自查**：形成三份MD，检查关键结论、来源、日期、读取层次、研究去重及覆盖缺口。

### 验收标准

- 每个主题能回答“具体问题、代表进展、为什么关注、仍缺什么”。
- 每条关键事实能回到明确来源及研究记录，区分原文结论与执行者推断。
- 五类初始问题均检查过；没有符合条件的材料可以留空，说明覆盖不足或未检索到。
- 不把议程、转载、同研究重复发表算作多项独立成果。
- 清楚标出已核事实、摘要级证据、待核信息及采集失败；不以“搜索过”代替取得材料。
- 来源覆盖有限时保持探索性结论，不冒充年度全景，不生成无依据的热度分数。
- 可以从任一主题追溯到研究、来源和团队，供下一步讨论是否深入。
