**用户于2026-11-11指出：需要的是研究领域的热点动态追踪工作台，之前围绕三个问题组织的研究台偏离了重点。** 本文件记录调整后的产品定位和更新口径；营销大方案保留。

[打开热点动态追踪台](热点动态追踪台.html)

## 主页面要回答什么

1. **近期发生了什么？** 按原始发表时间浏览研究结果，包含正面、阴性和安全性结果。
2. **哪些方向值得持续关注？** 把具体进展归为候选热点，显示关注理由、支持来源和证据边界。
3. **会议将讨论什么？** 跟踪议程与报告；计划议题单列，后续补结果。
4. **判断发生了什么变化？** 有新批次后，记录证据增加、成熟、冲突或主张收窄。

问题深研用于点开热点后的进一步分析，保留[[wenxin/糖尿病热点知识地图/05 研究台|原问题研究台]]与[旧版HTML](研究台.html)，不再占据主界面。

## 三个层次分开

| 层次 | 内容 | 当前能做的判断 |
| --- | --- | --- |
| 具体研究进展 | 某篇论文或某项已取得结果的研究 | 什么人群、什么方法、出现什么结果，局限是什么 |
| 候选热点 | 同一临床或科学问题下的多条线索 | 为什么值得继续观察；尚不自动等于领域共识或年度最热 |
| 会议关注信号 | 议程中的计划题目、讲者与研究方向 | 说明被安排讨论，不证明已有结果或临床用途 |

原六主题地图提供问题分类，不能仅凭主题名称称为热点。初版围绕具体进展归并8个候选观察主题；本次接入ADA后增加3个方向，当前11个；论文与会议同研究版本去重，篇数与议题数仅表示本轮覆盖，不表示热度。

## 当前版面与功能

- **近期动态**：论文进展按已核在线日期排序；可按候选主题、30／90天、首发日期待核及关注偏好筛选。
- **候选热点**：关注理由、支持来源、证据成熟度与限制；可关注主题，再回到对应进展。
- **会议动向**：CDS待报告议题与ADA已读取范围分开呈现，其他来源标覆盖状态。
- **来源与覆盖**：展示检索范围、批次记录、待核日期和下一轮应补的变化。
- 可导出当前筛选范围的进展简报。浏览器仅保存关注偏好；资料本身仍以Obsidian记录维护。

## 后续怎样形成动态追踪

每次实际采集后新增批次，至少保留：

| 字段 | 用途 |
| --- | --- |
| 研究ID、DOI／注册号／会议摘要号 | 关联同研究版本，防止重复放大 |
| 原始发表或报告时间、日期依据 | 形成真实时间顺序；未知时留空 |
| 本项目首次登记时间、最近核实时间 | 区分“新发现资料”和“新发表研究” |
| 来源、类型、读取层次、研究设计 | 区分议程、摘要、全文和验证层次 |
| 主题关联、关注理由、判断状态 | 解释归入何种候选热点及依据 |
| 与上一批的变化 | 新研究、版本升级、独立验证、冲突、修正或撤回 |

已有主题仍沿用任务书的四维判断：关注信号、新增价值、临床／科研意义、证据成熟度。只有覆盖与去重口径可比较，才讨论关注变化；新增文章数也不能直接作为“升温”判断。

持续闭环为：**实际采集 → 版本关联与去重 → 进展记录 → 主题判断更新 → 工作台展示 → 简报／进一步研究**。当前完成了首轮内容与展示，后续采集尚待执行；不会因为有HTML就自动形成持续追踪。

## 后续计划：主题分析与趋势展示｜2026-11-12

用户认可将主题趋势展示纳入计划，同时明确当前优先梳理“展示哪些主题、重点是什么”。建设顺序为：**明确主题与首批重点 → 固定主题定义及采集范围 → 建立可比历史基线 → 展示趋势并持续更新**。

- **已纳入后续计划**：主题×时间热图、选中主题的趋势曲线、关键证据时间线。研究数量、领域占比、团队广度及证据进展分别解释。
- **当前讨论重点**：区分临床科研主线、可持续追踪的具体问题、技术标签与来源标签；复核现有九个覆盖板块、十八条候选主题的粒度、重叠及业务重点。主题结构与优先顺序尚待确认。
- **后续数据准备**：固定来源与纳入规则，按可获得材料回溯历史窗口；现有定向精选记录用于梳理问题和证据，不直接生成领域升温排名。
