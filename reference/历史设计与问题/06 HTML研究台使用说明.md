# HTML研究台：版面与使用

> 本页对应问题深研旧版。按用户反馈，当前主入口已改为[热点动态追踪台](热点动态追踪台.html)；见[[wenxin/糖尿病热点知识地图/07 热点追踪口径与更新记录|新版定位与使用]]。旧版仍可继续导出已有任务和笔记。

**[打开研究台.html](研究台.html)**。在文件夹里双击该文件，用浏览器打开即可；Obsidian内若显示源码，请选择用默认浏览器打开。

## 页面怎么排

| 位置 | 内容 | 用来做什么 |
| --- | --- | --- |
| 顶部 | 搜索、当前页面、导出按钮 | 快速找资料与保存研究记录 |
| 左侧 | 工作台、CDS议题、文献证据、资料缺口；三个研究问题 | 在材料和具体问题之间切换 |
| 中间 | 当前问题、研究范围、证据、局限、相关议题 | 判断目前知道什么、还缺什么 |
| 右侧 | 下一步任务、本轮笔记、资料入口 | 推进研究并留下过程 |

配色用浅灰蓝底、白色阅读区和青绿色重点；待核的会议线索用浅琥珀色。手机宽度时自动变为单列，任务与笔记位于证据内容之后。

## 可以做什么

- 切换三个研究问题；查看关联会议议题和背景论文。
- 在23条CDS议题中按方向筛选，搜索讲者、单位、技术或编号。
- 在15篇论文中按期刊筛选，展开设计、结果与证据边界。
- 勾选任务、填写本轮笔记；记录保存在当前浏览器，可用“导出当前研究记录”下载MD。
- 点击Obsidian链接回到原笔记，点击来源链接查看PubMed、期刊或官方会议页面。

**保存范围**：浏览器记录不会自动写回Obsidian；清除浏览器数据、换浏览器或移动文件后，原记录可能不可见。需要长期留档时，先导出MD并放回项目中。勾选任务由使用者维护，不等于证据已完成专业核实。

## HTML怎样建立与更新

这个文件把三部分放在一起：**HTML组织内容，CSS控制版面，JavaScript负责切换、搜索和本地记录**。当前内嵌了本项目JSON中的论文与议题，任务来自[[wenxin/糖尿病热点知识地图/05 研究台|MD研究台]]；不依赖外部字体或脚本。

它是资料快照，修改原笔记后需要重新生成HTML。生成脚本在`来源/生成研究台.py`，本机运行`python3 生成研究台.py`会读取项目数据并覆盖`研究台.html`；更新界面设计前应先保留当前HTML版本。
