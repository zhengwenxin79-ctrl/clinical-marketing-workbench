# ADA还需要覆盖与收集什么

**现有6条是偏向组学与部分技术的定向样本，不能代表ADA大会全貌。** 本次对照官方程序、官方临床试验报道及遴选摘要表，确定扩展范围。这里列的是待采集／补核方向，不把已找到新闻标题当成新入库热点，也不改写工作台现有6条的结果状态。

## 先明确两层目标

- **领域雷达层**：了解哪些临床研究、治疗策略、疾病修饰或技术进展正在改变问题背景。即使公司当前不直接承接，也应知道。
- **临床科研深挖层**：从这些进展中提取应答差异、残余风险、患者分层、早期识别和可验证标志物，再关联组学方法和研究团队。

不只选题目里有“Biomarker”“组学”的报告。新治疗、负面试验和长期结局，也可能提出更具体的临床科研问题。

## 应覆盖的九个板块

以下为面向工作台的建议归类，不是照搬ADA的官方分类，也不表示每个板块已经构成热点。

| 板块 | 具体要收集什么 | 当前缺口 |
| --- | --- | --- |
| 新药与联合治疗 | 口服GLP-1RA、amylin联合、双／三受体方案；关键临床试验、头对头比较、安全性 | 只有ACHIEVE-5题目，漏多组大会临床研究 |
| 肥胖、缓解与长期维持 | 体重与体成分、肌肉／功能、停药后维持、缓解定义与持续时间 | 尚未建立成套结果；单纯肥胖且无糖尿病数据的研究作邻域背景 |
| 心肾肝眼等结局 | 心血管／肾脏等临床结局、糖网、神经与足病；残余风险和不良反应 | 偏肾机制，不能据降糖或体重替代器官结局 |
| T1D疾病修饰与细胞替代 | 早期筛查、免疫干预、β细胞保留、胰岛／细胞替代；终点、免疫抑制与长期安全 | 工程细胞只有题目，缺疾病修饰和临床使用条件 |
| CGM、AID与数字／AI技术 | 人群与场景扩展、随机效果、真实实施、低血糖与患者负担 | CONNECT仅基线，1063-OR不完整，未覆盖AIDING主试验 |
| 分型、标志物与风险模型 | 蛋白／代谢／遗传／免疫及动态测量，增量价值、外部验证、转化条件 | 只有纵向蛋白和一项肾内单细胞研究，疾病分型和早期风险不足 |
| 机制与转化方法 | 胰岛、免疫、细胞互作与分子代谢；单细胞、多组学等怎样连接临床表型 | 缺少从机制到临床问题的系统关联；不平均收所有基础通路 |
| 特殊与高风险人群 | GDM／母婴、儿童青少年、老年、不同族群与疾病阶段 | 孕期及年龄差异未覆盖，不能用普通成人T2D外推 |
| 预防、生活方式与实施 | 饮食、运动、行为、心理、食物获取、可及性、成本及真实世界应用 | 几乎未覆盖；可帮助理解研究能否进入实际管理 |

## 下一批首先追哪些具体入口

### A. 先补大会关键临床结果

- **REIMAGINE 1／2／3**：CagriSema研究系列；三项研究分别记录，不把整个系列合成一项。已有[ADA官方会后结果报道](https://diabetes.org/newsroom/press-releases/once-weekly-cagrisema-amylin-semaglutide-combination-injection-more)，下一步追各试验摘要、论文与注册号。
- **ACHIEVE-2／3／5**：补齐比较对象与不同背景治疗。已有[ADA官方结果报道](https://diabetes.org/newsroom/press-releases/achieve-trials-demonstrate-comparative-benefits-novel-small-molecule-oral)，其中ACHIEVE-5与现A04关联；不能重复增加研究数。官方程序物理第365页；1254-OR另见第278页。
- **SOLSTICE／VISTA**：作为另一组口服治疗进展入口；[官方会后临床试验目录](https://www.adameetingnews.org/category/scientific-sessions/2026/clinical-trials-2026/)已列，分别核实人群和结果。
- **TRANSCEND-T2D-1／TRIUMPH-1，以及SYNCHRONIZE相关研究**：官方会后目录有入口；分别标T2D研究、肥胖或肝病邻域研究，不把无糖尿病受试者的结果当糖尿病疗效。
- **AIDING**：已有[官方会后报道](https://www.adameetingnews.org/automated-insulin-delivery-demonstrates-efficacy-in-glycemic-management-in-the-hospital/)，程序物理第179页。要核实它与现A05／1063-OR之间是主试验、亚组或不同研究，不能直接合并结果。
- **CONNECT／1170-OR**：补最终结果；现A03仅设计与基线，需要追最终摘要／报告／论文。

以上官方报道是定位结果的入口，仍需取得原始摘要、论文或注册结果；新闻报道层与原始研究层分开。

## 每个研究应收集到什么程度

每条最终要能回答：**发生了什么—相较已有证据新增什么—为什么值得持续关注—下一次什么证据会改变判断**。

1. **身份与版本**：摘要号、DOI、注册号；主试验、亚组、二次分析、随访与重复报告关系。
2. **日期与来源**：实际报告日、首次发表日、官方报道日、本项目收录日；结果是否已取得。
3. **研究设计**：病型／阶段、人群、地区、人数、样本、干预／对照、随访、终点。
4. **结果与边界**：主要效应量与区间、绝对／相对变化、安全性、阴性结果、局限及读取层次。
5. **热点判断**：新增价值、独立团队及跨来源信号、临床意义、证据成熟度；不能用新闻篇数代替热度。
6. **后续关联**：团队与报告人角色、与CDS的共同问题、待补验证，再做公司能力匹配。

## 执行顺序

**先检查大会重点临床试验与会后结果目录，补齐6条的关键缺口；再补分型／风险／器官结局与特殊人群，最后按主题深入机制和实施。** 领域雷达不能完全受现有公司产品限制，深挖顺序再结合临床科研业务。

每个板块优先选择足以改变当前判断的研究，不机械规定篇数。关键试验覆盖、原始结果可回查、阴性证据保留、重复研究识别，比把“6”增加到某个数字更重要。

本次完成覆盖审计、会后来源与候选入口定位。尚未逐项精读这些扩展研究、提取全部结果，也没有将它们直接计入HTML的已收录热点数。
