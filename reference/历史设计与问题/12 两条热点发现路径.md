# 两条热点发现路径

> **当前侧栏与样式｜2026-11-11**：侧栏只保留两个可展开主模块：**产品与技术动态 → 7类产品技术**；**会议热点洞察 → 9类自建研究主题**。全部动态、其它热点、候选热点与来源放入顶栏“资料与记录”。已参考基金平台深蓝版本统一配色、字体、顶栏、卡片和导航；以下早前讨论与修订按顺序保留。


[打开工作台](热点动态追踪台.html) · [[wenxin/糖尿病热点知识地图/00 项目主页|项目主页]]

用户提出将框架换成两个模块：从外部产品相关进展寻找热点，以及从会议热点入手。本次据此按**发现路径**组织两个主入口，产品关联程度、疾病和技术则用于筛选与判断。

## 模块一：产品与技术动态

**外部产品/技术 → 应用与研究进展 → 临床问题 → 公司能力匹配。**

| 环节 | 内容 |
| --- | --- |
| 输入 | 外部同类产品与技术更新、原始论文、应用案例、方法与验证研究 |
| 提取 | 技术测什么、样本与流程、用于什么疾病问题、出现什么新结果、有哪些局限 |
| 输出 | 技术相关进展卡、候选方向、公司能力关联与待核项、下一条值得追的证据 |
| 例子 | 从cfRNA入手，找到GDM孕期早期风险研究；再区分外部研究流程与公司捕获方案的适配条件 |

当前页面提供cfRNA、cfDNA甲基化/GM-seq、单细胞/单核、空间组学、免疫组库、蛋白与代谢等入口。研究是否实际使用某类技术与公司是否可按相同流程交付，仍然分开记录。

**当前已有数据主要是论文和摘要，尚未系统采集外部产品发布、商业版本更新与独立应用案例。** 页面明确该覆盖缺口，不把论文算成新产品上市。

## 模块二：会议热点洞察

**国内外核心会议 → 议题/摘要/报告结果 → 候选热点 → 相关技术与团队。**

| 环节 | 内容 |
| --- | --- |
| 输入 | 核心会议日程、报告题目、原始摘要、最终结果及对应论文 |
| 提取 | 大会在讨论什么问题，出现什么结果，是否改变已有认识，相关方法与团队是谁 |
| 输出 | 会议关注方向、具体研究证据、与产品/技术的关联、待核结果与后续追踪线索 |
| 例子 | 从ADA孕期研究发现早期识别与诊断边界问题，再查CGM及cfRNA等方法；不同方法须分别核证，不能互相替代性能 |

当前已有ADA 27条研究记录、CDS 23条计划议题。页面先呈现从现有会议证据归纳的五个关注方向，再进入具体记录：口服GLP-1RA、amylin联合、CGM/数字干预、孕期预测诊断、T1D纵向测量与多组学。此处为本轮分析，不代表年度热度排名或大会完整覆盖。

已取得结果、官方报道与计划议题仍分层；作者、计划报告人和实际报告人不混同。

## 两条路径共用同一热点库

同一研究可能从产品技术检索和会议两边被发现。沿用研究ID、DOI、注册号和摘要号建立版本关系，不为两个入口复制两份研究或放大热度。比如A01/R03继续按同研究版本合并展示。

共享筛选与判断包括：疾病领域（目前糖尿病）、技术、具体临床问题、来源时间、证据层次、公司关联程度和待补内容。当前不扩展到尚未采集的其它五领域。

“其它热点”和“关联待判断”继续保留在共用资料中；全部动态、候选热点、来源覆盖也在共享资料区，可从两个主模块随时进入。低关联研究仍可在会议路径被发现，不因没有对应产品而丢失。

## 九大板块侧栏｜2026-11-11

按用户要求，把九大板块由正文下拉筛选移到侧栏，板块目录与每个板块均可展开/收起。每个板块显示已归类研究记录数，展开后可查看全部热点或进一步按关联主题浏览；点击后进入共用动态库，并在正文显示当前筛选及清除入口。切换页面保留本次展开状态。计数按去重展示记录，允许跨板块关联，不代表热度；CDS计划议题仍在会议模块单列。

桌面默认展开目录并支持侧栏滚动；手机默认收起，可展开查找。本次仅调整导航交互，沿用B03研究数据与两个主模块，无新增采集。

## 产品技术侧栏与分类归属｜2026-11-11

用户要求将cfRNA、甲基化、单细胞等技术也放入可展开侧栏，点击直接查看糖尿病相关动态；随后指出“九大板块”在页面上没有归属。

原九板块来自[[wenxin/糖尿病热点知识地图/09 ADA覆盖扩展与采集清单|采集覆盖清单]]，本意是检查是否遗漏新药、器官结局、特殊人群、机制及实施等方向，是项目自建的工作分类，不是ADA官方分类，也不是公司产品目录。直接与产品技术并列没有说明其作用与所属层级。

现将侧栏明确组织为：

- **产品与技术动态 → 产品技术分类**：7类技术目录可展开/收起，点击任一技术直接打开“该技术 × 糖尿病热点动态”；正文原技术卡片移除，当前技术显示在标题中。
- **会议热点洞察**：保留由会议进入研究结果的路径。
- **糖尿病领域 → 研究主题（9类·自建）**：两条发现路径共用的研究问题分类；保留展开、查看全部或子主题功能，并可点击分类依据回到采集清单。
- **共享资料**：全部动态、候选热点、其它热点和来源记录。

产品技术与疾病研究主题是两个不同维度。点击产品技术会清除先前板块/搜索等条件，直接显示该技术当前已入库的糖尿病研究；暂无已核资料时保留空状态说明。桌面目录默认展开，手机默认收起，切换页面保留本次展开状态。未改变研究数据、公司能力状态或采集批次。

## 双模块与基金平台样式｜2026-11-11最终调整
