# CDS 2026：先从议题建立国内研究地图

**现在可以直接开展议题研究。会议是否已经召开，影响的是结果核实，不妨碍我们先识别临床问题、研究方法和团队线索。**

本次按用户意见，将CDS从“等待会后”的来源，推进为当前国内问题发现的入口。路径为：

**议题 → 临床科研问题 → 已有文献 → 还缺的证据 → 会中／会后追踪。**

[官方详细议程](https://cds26.tiemeeting.com/CN/Program/Details)已保存本地快照。题目、日期、场次、计划讲者与单位来自议程；下面的问题改写、研究顺序和关联判断为本轮分析。首轮原有15篇论文作为背景复用，本次不增加正式论文数量。

## 先研究三类问题

### 1. 同样是糖尿病，哪些患者需要不同的研究和干预？

从患者差异出发，先问分型有没有临床意义，再选择检测技术。重点追踪**OR_031、S_029、OR_092**，分别连接β细胞功能表型、T1D异质性和GDM中特殊病型识别。

- **已有基础**：R01提供组织层面的亚型差异；R02提供遗传与应答线索；R04／R13支持继续讨论免疫与代谢分层。
- **需要核实**：分型使用什么变量，是否在独立队列复现，能否改善常规临床判断，是否改变治疗选择。
- **研究输出**：一张“人群—分型依据—临床差异—验证条件”问题卡。不同病型的证据分别保存。

### 2. 常规指标还正常时，怎样识别已经出现的损伤？

先追**OR_003、OR_005**。研究重点是提前识别和进展差异，而不只是发现组间表达不同。

- **已有基础**：R11讨论正常白蛋白尿人群的候选蛋白；可作为问题背景。**它与CDS OR_003尚未确认属于同一研究**，不得合并人数、结果或团队。
- **需要核实**：纳入人群、损伤参照标准、采样与终点时间，以及新指标超出UACR／eGFR等信息的价值。
- **研究输出**：一张“临床盲区—候选指标—参照标准—预测增益”问题卡。

### 3. 怎样区分眼、肾、心等不同器官的风险？

以**OR_007、S_198、OR_333**为起点，S_200提供影像测量的邻近路径。先明确预测哪个结局，再讨论代谢物、蛋白或影像如何参与。

- **已有基础**：R03提示纵向蛋白测量的研究价值；现有材料仍偏肾脏，不能替代眼病或心血管结果。
- **需要核实**：单器官／多器官终点、横断面识别／纵向预测、共病混杂、外部验证和临床可用性。
- **研究输出**：一张“器官结局—样本与测量—随访—验证队列”问题卡。

**以上是适合当前临床科研Biomarker主线的研究顺序建议，不是会议热度排名，也不是公司已具备承接能力的判断。**

## 怎样把议题接到文献

研究时不要只用中文题目逐字搜索。先拆成四类词：**人群／疾病阶段、临床问题、测量方法、结局**，再加讲者、单位或具体分子追踪。下面是下一批可运行的组合，不代表这些检索已经完成。

| 问题 | 英文检索词组合示例 | 与现有台账的关系 |
| --- | --- | --- |
| 异质性与应答 | diabetes subtypes / beta-cell failure / treatment response / external validation | R01、R02、R04、R13是背景，逐项核是否同研究 |
| 隐匿肾损伤 | type 2 diabetes / normoalbuminuria / tubular injury / transcriptomics / prospective cohort | R11背景；OR_003的论文、注册号和完整摘要待取得 |
| 多器官风险 | diabetes / retinopathy / kidney disease / circulating biomarkers / metabolomics / longitudinal | R03背景；眼／心原始研究需要新增 |

对于每条拟深入议题，最终补齐：**摘要／论文标识、研究人群、样本、设计、结果、独立验证、局限和团队角色**。论文题目近似或作者重叠只能提出版本关联候选，确认后才去重。
