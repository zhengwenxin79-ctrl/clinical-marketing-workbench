## Q01 患者分型

**要回答**：在明确的T2D人群中，β细胞功能或分子特征形成的亚群，能否改善常规临床分层及治疗应答判断？

**先限定范围**：先围绕T2D β细胞功能分层。T1D免疫亚型与GDM中特殊病型识别保留在议题池，分别追证据，避免将不同病型混成一套分型。

- **议题入口**：[CDS OR_031](https://cds26.tiemeeting.com/CN/Program/Details#session40605)。S_029、OR_092作为相邻问题，见[[wenxin/糖尿病热点知识地图/04 CDS议题与研究问题|CDS议题索引]]。
- **已有论文**：[[wenxin/糖尿病热点知识地图/02 研究进展记录#R01｜T2D临床亚型的胰岛单细胞差异|R01 T2D临床亚型的胰岛单细胞差异]]；[[wenxin/糖尿病热点知识地图/02 研究进展记录#R02｜GLP1R变异与药物应答|R02 GLP1R变异与药物应答]]。
- **目前能说**：已有不同层次的分型与应答线索，值得进一步研究其临床意义。它们与OR_031的版本关系尚未核实。
- **关键缺口**：亚群定义、患者数、对照模型、治疗应答终点、外部复现及中国人群适用性。

待完成：

- [ ] 取得OR_031完整摘要或对应论文；未找到则记录查询与结果。
- [ ] 将临床聚类、组织分型、遗传应答分别列出，核对是否回答同一个问题。
- [ ] 填出“人群—分型依据—临床差异—验证条件”对照表，再决定是否值得深入。

**阶段交付**：一页分型研究比较与判断；每条结论指向研究记录。公司承接能力后续确认。

## Q02 隐匿损伤

**要回答**：对于白蛋白尿尚未明显异常的糖尿病患者，哪些新增测量能识别损伤或预测未来进展？

- **议题入口**：[CDS OR_003／OR_005](https://cds26.tiemeeting.com/CN/Program/Details#session40603)。
- **已有论文**：[[wenxin/糖尿病热点知识地图/02 研究进展记录#R11｜正常白蛋白尿仍发生肾功能下降|R11 正常白蛋白尿仍发生肾功能下降]]；此前代谢库E06为同一论文，沿用记录。
- **目前能说**：现有摘要提供补充常规指标的候选线索。CDS OR_003与R11尚未确认同研究，队列和数字分别保存。
- **关键缺口**：入组条件、检测样本、损伤判定标准、未来结局、与UACR／eGFR等模型比较，以及独立验证。

待完成：

- [ ] 优先取得R11正文，补齐设计、人数及检测方法；获取失败则保留摘要层级。
- [ ] 追踪OR_003对应研究，核对其与R11的作者、队列、标识和时间。
- [ ] 区分“识别现有损伤”和“预测未来进展”，分别评价新增信息。

**阶段交付**：一页“临床盲区—测量对象—验证设计—仍需证据”的问题卡。

## Q03 器官风险

**要回答**：在糖尿病人群中，眼与肾病变是否有不同的风险信号，这些差异是否足以支持分别预测？

**先限定范围**：先追眼／肾两个结局，心血管作为后续扩展，避免一次铺开所有器官。

- **议题入口**：[CDS OR_007](https://cds26.tiemeeting.com/CN/Program/Details#session40603)；[S_198／S_200](https://cds26.tiemeeting.com/CN/Program/Details#session40563)。OR_333列为心肾代谢扩展线索。
- **已有背景**：[[wenxin/糖尿病热点知识地图/02 研究进展记录#R03｜纵向蛋白组与发病风险|R03 纵向蛋白组与发病风险]]；[[wenxin/糖尿病热点知识地图/02 研究进展记录#R11｜正常白蛋白尿仍发生肾功能下降|R11 正常白蛋白尿仍发生肾功能下降]]。R03可帮助理解纵向测量，R11提供肾风险背景；二者不能代替眼病研究结果。
- **关键缺口**：眼／肾结局定义、结局时间、临床混杂、共同／特异信号、模型增益、独立验证及样本可获得性。

待完成：

- [ ] 取得OR_007原始摘要或论文，记录研究人群、样本和随访。
- [ ] 补至少一项直接讨论糖尿病眼病风险的原始研究，标明是否真正纵向预测。
- [ ] 比较代谢物、蛋白和影像分别回答什么，不将技术间的主题关联当独立验证。

**阶段交付**：一页“器官结局—测量—时间—验证”的对照表，保留无法比较之处。

## 每次研究怎样留下结果

**待检索 → 待核实 → 待判断 → 可形成研究选题。**

推进时填写本页的“当前状态”和“下一项工作”；完成的原子任务再勾选。新研究写入[[wenxin/糖尿病热点知识地图/02 研究进展记录|研究台账]]，查询失败与覆盖变化写入[[wenxin/糖尿病热点知识地图/03 来源覆盖与缺口|来源审计]]。正文资料存入本项目`来源/`，问题卡链接回记录。

| 一次研究至少留下什么 | 放在哪里 |
| --- | --- |
| 查询内容、来源、日期及找到／未找到什么 | 来源审计；保留实际执行记录 |
| 人群、样本、方法、主要结果、验证与局限 | 研究台账；标明摘要／全文 |
| 本轮理解发生了什么变化，哪些问题仍未解决 | 对应Q问题卡的“本轮判断” |
| 下一项能改变判断的工作 | 本页工作表与问题卡 |

形成选题之前，需要先明确临床问题、可获取样本、可测对象和验证条件。再查[[wenxin/实习实践/吉因加临床科研能力表|公司能力表]]及[[wenxin/实习实践/临床科研营销知识包/00 知识包总览|公司知识包]]，注明已确认与待核状态，逐步进入能力和团队匹配。
