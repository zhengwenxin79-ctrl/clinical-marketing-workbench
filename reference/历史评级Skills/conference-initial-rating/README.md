# 临床科研会议初评 Skill

帮助吉因加市场产品经理筛选：**哪些会议可能聚集希望合作的临床科研PI，值得优先关注并进一步了解相关研究团队？**

适用于会议抓取之后、客户拆解之前，不需要先准备完整产品库或客户信息。

## 怎么判断

**相关领域、经官方资料确认的全国性专业学会或其专科分会正式年会，优先列为“重点关注”。** 即使日程、PI名单或本届人数尚未查到，也保留重点关注，在备注中写待补信息。非覆盖城市同样适用；仅有“全国”标题或第三方日历时，先核实正式身份。

其他会议主要看三件事：

1. **研究团队：**公开信息中，是否有相关临床研究负责人或团队参与的线索。
2. **科研内容：**是否有临床研究、队列、多中心研究、疾病机制、标志物或转化研究等交流内容。
3. **区域：**是否在销售覆盖城市；外地会议是否有值得重点关注的核心价值。

不打百分制分数。其他会议的规模、级别和主办方作为参考，小型专业会议也可以重点关注，缺少人数不直接降级。

## 关注范围

- **领域：**自免、内分泌、神经精神、心血管、慢阻肺、泛血管。
- **城市：**北京、上海、杭州、苏州、南京、长沙、广州、深圳、成都、重庆；外地核心会议可保留。
- 纯器械操作、手术或介入操作培训不重点考虑；综合大会可只关注相关分会场。

## 日期地点怎么核实

以本届最新正式通知、更正通知或大会官网更新为依据，年度计划和第三方日历作为线索。发现冲突则注明待核实，不直接把计划日期已过写成“已结束”。

确认改期到目标周之外的，移出该周已确认会议清单；仍有冲突的列为待核实候选。会议值得关注与安排尚待核实可以同时成立。

## 输入与输出

**输入：**会议清单、官方通知、网页、海报或日程，不要求完整参会名单。

**输出：**保留原会议清单，补充“重点关注／常规关注／低优先级／待确认”，每场用1—2句话解释理由，指出重点专题、来源及必要的待核实事项。

## 使用示例

> 请使用临床科研会议初评 Skill，优先关注相关领域经核实的正式全国性学会或分会年会，结合临床科研交流价值和覆盖城市判断其他会议。核实最新日期地点，保留原表格式，给出关注等级、简短理由和待补信息，输出供辛小青审核的版本。
