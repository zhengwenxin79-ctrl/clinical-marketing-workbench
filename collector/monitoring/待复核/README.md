## 词条及计数

据既有资料人工归纳28个词条，涵盖具体分子、遗传变异、组合、指标类别和成员待核的特征集合。默认26个研究词条（含4个仅有计划议题的词条），HbA1c/TIR等纯常规参照与终点通过“词条范围”切换显示。每项研究内的具体用途分别记录；同一词条可以属于多个用途分类。

词云大小按**当前分类下已收录的去重研究记录数**计算，A01/R03合并；每类数量不能直接相加。计划议题不计入研究数量，以灰色虚线显示。记录数不代表领域总体热度、独立验证数或上升趋势，共享队列和亚组关系待核处保留说明。阴性结果、机制线索和未取得结果的记录均按原状态展示。

吉因加匹配按词条的测量对象、样本和研究用途单独整理，不自动继承整篇研究的技术标签；文献技术关联、方法参考及公司现行交付范围分别说明。比如C肽作为代谢组研究的终点，不据此赋予其代谢组检测匹配。
